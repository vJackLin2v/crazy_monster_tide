## 1. 产品定位

一款竖屏、像素风、自动攻击型肉鸽微信小游戏。核心体验参考幸存者类和构筑类肉鸽，**但不复制现有产品内容或美术**。

核心卖点：

> **4 个主动技能 + 每个技能 3 个可插拔行为槽 + 可重复行为模块 + 道具/属性/标签联动。**

玩家不需要手动释放技能，主要操作是移动；爽感来自自动攻击、数量增长、范围扩张、技能变异、Build 成型、怪物潮和强反馈。

---

## 2. 核心玩法

- 玩家选择一个角色开始一局。
- 每个角色拥有固定被动，并包含明显的正向 Buff 与负向 Buff。
- 玩家在战斗中最多持有 4 个主动技能。
- 主动技能自动攻击。
- 升级奖励可从 4 类中抽取：技能、行为模块、道具、属性加成；每次横向 3 选 1。
- 行为模块可以安装到任意兼容的主动技能槽位。
- 每个主动技能最多 3 个行为槽。
- 行为模块可以重复安装，除非该模块定义为唯一/不可重复；重复模块按自身叠加规则生效。
- 玩家可以在 Build 面板中重新分配已拥有的行为模块到其他技能。
- 地图采用树形路线，每个节点可选择不同风险/收益。
- 精英节点提供高级道具或高级行为模块的主要来源。
- Boss 节点用于阶段性高潮。

---

## 3. 操作

- 角色自动攻击，不设计主动技能施法按钮。
- 移动使用动态摇杆：玩家触点落下时在触点附近生成摇杆；松开后消失。
- 战斗 HUD 不显示大块技能按钮，技能只作为状态信息展示。
- 暂停后进入详细 Build 面板，可查看技能、行为模块、道具、属性。

---

## 4. 战斗 HUD

- 顶部：HP、经验、等级、暂停。
- 技能状态栏：4 个技能图标，每个技能底部显示最多 3 个行为槽的缩略标识。
- 底部：主要作为移动输入区域，不固定放置摇杆。

---

## 5. 升级 UI

- 全屏或主要面板横向展示 3 张选择卡。
- 奖励类别：技能 / 行为模块 / 道具 / 属性加成。
- 行为模块奖励在选择后进入「安装目标」步骤，可选择已有技能中兼容的槽位。

---

## 6. 角色选择

首版角色数量控制在 **6 个**左右，结构参考构筑型肉鸽的角色选择方式：角色列表 + 当前角色详情 + 正负天赋 + 初始技能 + 开始按钮。

---

## 7. 怪物与打击反馈

已有约 **70+** 怪物素材，因此 MVP **不以增加怪物种类为优先**。重点是：

- 受击白闪
- 命中 VFX
- 打击音效
- 轻微击退 / 受击反馈
- 伤害数字
- 精英 / Boss 更强的命中反馈与镜头反馈

---

## 8. 素材原则

正式开发必须先进行素材评估：明确需要什么、已有多少、哪些可直接用、哪些需要标准化/改造、哪些缺失、授权是否明确。

缺失素材优先顺序：

```
已有素材改造 → 网络合法素材 → AI 生成/改造 → 占位
```

占位素材**不得**被悄悄当作最终素材（必须在 `docs/assets/asset_gap.md` 留痕）。

---

## 9. 原型原则

正式引擎 UI 前，先完成**可玩的 HTML MVP**。HTML 原型必须体现核心循环，而不是只展示静态页面。

HTML/UI 迭代确认后，冻结 UI Spec，再在正式引擎中实现。

## 11. 命名与市场定位（2026-10-12 调研固化）

**结论：中文名《疯狂怪潮》**，工程目录 `crazy_monster_tide`。

调研依据（2026 年微信小游戏真实榜单）：

- 畅销榜长期头部：《无尽冬日》《向僵尸开炮》《三国：冰河时代》《疯狂水世界》《我的花园世界》《道友来挖宝》《跃动小子》《无限轮回》《生存33天》《保卫向日葵》。
- 2026 年 9~10 月人气榜/热玩榜新入榜：《有种来闯关》《开局一条枪》《解压来捞菜》《我在废土独自升级》《造个大英雄》《闯关太疯狂》《万妖图录卷》《上个了车》。
- 归纳出的爆款命名句式：
  1. `疯狂 + 名词`（疯狂水世界、闯关太疯狂）
  2. `向 X 开炮`（动作指令式，强画面感）
  3. `开局 + 一句梗`（开局一条枪）
  4. `我的 + X + 世界`（我的花园世界）
  5. `无尽 / 无限 + X`（无尽冬日、无限轮回）
  6. 口语短句（有种来闯关、解压来捞菜）

**《疯狂怪潮》** 命中句式 1 + 直指本作核心内容（怪潮 + 割草），4 字好记、好喊、无生僻字、与现有产品不重名（已检索无同名游戏）。

上线前仍需执行（未完成，见 §12）：
1. 微信小游戏平台名称查重；
2. 商标检索；
3. 备选名登记（`怪潮太多啦` / `开局四技能` / `满屏都是怪`）。

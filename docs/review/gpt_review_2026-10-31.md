## 0. 一句话说明

这是一款**竖屏像素风、自动攻击、构筑向割草肉鸽**：玩家只负责走位，4 个技能自动开火；每个技能最多插 3 个「黑科技」改变弹道/元素/触发；每波结束进商店，升级三选一；20 波通关，每 5 波 BOSS，通关后可进无尽。

## 1. 核心循环

```
主菜单 → 难度 → 选角 → 战斗（1~20 波，每波 20~60s）
   ├─ 击杀掉经验球 → 升级 → 暂停 + 3 选 1（技能/强化/黑科技/道具/属性）
   ├─ 每 5 波 BOSS；非 BOSS 波有精英（绿色泛光 + 冲锋/扇形红球）
   ├─ 波结束 → 商店（买/锁/刷新）→ 装黑科技 → 下一波
   └─ 死亡/通关 → 结算 → 历史战绩
```

胜负：生命归零失败；清完第 20 波通关，可继续无尽。每波开始**回满血**（第 1 波按难度初始生命）。

## 3. 操作与战斗

- 移动：虚拟摇杆/键盘；技能全自动。
- 4 个技能槽；每个技能 3 个黑科技槽。
- 升级：经验满→暂停→三选一（技能、技能升级、黑科技、道具、属性）。**暂停是设计行为**；选完必须恢复，历史上出现过「选黑科技→安装屏返回后仍暂停/phase 卡住」的 bug，已修并有恢复兜底。
- BOSS（每 5 波）三种技能：
  1. 5 向红色弹幕（0.45s 红圈预警）；
  2. 冲锋（方向预警 + 后撤蓄力）；
  3. 范围砸地（0.9s 预警圈）。
- 精英：绿色泛光 + 3 向红色扇形弹（0.35s 预警）+ 冲锋。
- 远程小怪：眼球蝠/魅魔/观察者/蛇怪，单发红球。
- 敌方弹幕统一红色球，与玩家金色/元素弹体区分。

## 4. 技能（20 个，详见附表）

每个技能：类型（projectile/orbit/trap/summon/charge/area/chain 等）、冷却、基础伤害、标签（物理/火/冰/雷/奥术/召唤/区域/蓄力等）。
示例：环刃（环绕）、地雷阵（陷阱）、哨戒哨兵（召唤）、蓄能脉冲（蓄力 3s 爆发）、毒雾（区域持续）、陨石（延迟爆发）、刃风（近身高频）等。

## 5. 黑科技（18 个，详见附表）

每个技能最多 3 槽，黑科技按标签兼容（projectile/area/pulse/chain 等）。
叠加上限分 additive/tier/unique；同名 3 个可合成 Ⅱ/Ⅲ（效果份数 1.6/2.2…，不是简单 ×2）。
核心黑科技：多重、散射、分裂、弹射、穿透、环绕、增大、冷却缩减、重复施放（echo）、灼烧、减速、吸血、连锁、狙击、击杀回血、落雷、反伤、强化伤害。
**审查重点**：组合爆炸（分裂+连锁+echo+落雷）、吸血+击杀回血+反伤的续航上限、冷却缩减与 echo 的叠乘、范围/体积对命中的影响。

## 6. 道具（T1~T3，详见附表）

T1 普通（商店/掉落），T2 高级（精英/BOSS），T3 传说（限 1 件）。
示例：金币袋、血契（攻击 +30%/最大生命 -25%）、极简专精（技能 ≤2 时增伤）、黑科技共鸣（同技能 2 个同类黑科技 +20%）、低血强化（<35% 攻速 +35%，否则 -8%）、受击反伤、刷新省钱、金币转攻击等。
**审查重点**：传说强度、负收益道具（血契/低血/少技能）是否值得、道具与黑科技的乘区叠加。

- 怪物成长：每波 HP +42%、伤害 +20%（线性）。
- 波次时长：第 1 波 22s，每 3 波 +4s（第 20 波约 46s）。

### 真机样本（用户 20 波通关，普通难度）

- 1246 杀、19 次商店、最终 HP 90/90；整局承伤合计约 770，且**每波开始回满**。
- 第 1~19 波结束血量多数 72/72；直到第 17 波才出现 165 承伤。
- 结论线索：普通难度威胁偏低、承伤主要被每波回满抵消；需要审查「回满 + 低承伤」是否让难度曲线失效。

## 9. 已知限制（请审查时考虑）

1. BOSS/精英有预警圈与弹幕，但没有专属骨骼动画/分层音效。
2. 普通难度未做逐项旧版对照；地狱经济 1.8225 倍只做过配置校准，缺真机数据。
3. 战斗实体层（碰撞/生成/动画）无引擎级自动化测试，主要为纯逻辑单测 + 浏览器/真机运行。
4. 升级期间暂停是设计；选完必须恢复（已修，含兜底）。
5. 商店「已有道具」详情仅展示，不可操作。

## 10. 建议审查的问题（详见提示词）

1. 20 波难度曲线是否合理？普通是否过于简单（结合样本）？
2. 黑科技组合是否存在无限循环/数值爆炸/必选组合？
3. 技能 4 槽 + 3 黑科技槽的构筑深度是否足够？
4. 道具 T1~T3 的强度梯度与负收益是否成立？
5. 商店经济（金币收入/价格/刷新/锁定）是否形成有效决策？
6. UI 在 360×640 下的信息层级、可读性、热区、遮挡。
7. 战斗可读性：玩家弹体 / 敌方红球 / 预警圈是否清晰区分？
8. 边界情况：升级时死亡、暂停中升级、商店中升级、波末升级、连续升级、安装屏返回。
9. 每波回满 + 低承伤是否破坏难度与道具价值？
10. BOSS 三技能与精英技能是否足够差异化、有反制空间？

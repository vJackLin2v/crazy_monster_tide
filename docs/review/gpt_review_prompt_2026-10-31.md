# 给 GPT 的审查提示词（可直接复制）

你是资深**游戏制作人 + 系统/数值策划 + UI/UX 评审 +  Roguelike 构筑设计评审**，请审查《疯狂鸽王》（竖屏像素风自动攻击割草肉鸽，Cocos 3.8.6，微信小游戏，360×640）。

## 你会拿到的材料

1. `REVIEW_DOC.md`：项目概览、系统说明、已知限制、真机样本；
2. `gpt_review_tables_2026-10-31.md`：全量技能 / 黑科技 / 道具 / 难度 / 全局数值表；
3. `screenshots/`：真实运行截图（menu_has_save / menu_no_save / levelup_paused / battle / shop / result / history_detail / codex / achievements / settings）；
4. 真机 20 波通关样本（普通难度）：1246 杀、19 次商店、最终 HP 90/90、整局承伤约 770、每波开始回满。

**约束**：
- 只基于材料与常识评审，不要臆造未提供的系统；需要假设时明确写「假设」。
- 区分「截图/表格证据」与「推断」。
- 不改变核心品类（自动攻击、4 技能、黑科技插槽、20 波 + 无尽）。
- 保持像素风与 360×640 竖屏；不考虑付费/赌博元素。
- 给出**可执行的数值/交互改法**，不要只说「优化一下」。

## 审查范围与必答项

### A. UI / UX
1. 主菜单：有/无存档两种状态的视觉焦点、按钮层级、玩法说明位置、底部图标可读性与热区；是否存在信息缺失或冗余。
2. 战斗 HUD：HP/EXP/金币/波次/击杀/倒计时/技能槽在 360×640 下是否清晰；技能名/黑科技点/冷却遮罩是否可辨；是否遮挡战斗。
3. 升级三选一：卡片信息量、暂停感知、是否说明「选择后恢复」；选卡期间看不到 HUD 是否会焦虑。
4. 商店：货架信息（名称/数值/价格/锁定）、已有道具网格、刷新/下一波布局；道具详情是否该只读。
5. 结算 / 战绩详情：信息层级、2×3 数据、技能构筑、道具全量滚动、结束原因；是否有重复/截断。
6. 设置 / 图鉴 / 成就：入口、返回、滚动、空态、文本截断。
7. 逐项给出：问题 → 证据（截图文件名/表格行）→ 影响 → 具体改法（尺寸/字号/间距/层级/文案）。

### B. 核心循环与节奏
1. 开局 60 秒是否能让玩家理解「走位 + 自动攻击 + 升级 + 商店」？
2. 每波 20~60s、20 波、每 5 波 BOSS 的节奏是否合理？空窗/疲劳点在哪？
3. 每波开始回满血是否必要？对难度、道具价值、吸血 build 的影响。
4. 暂停/继续、保存退出、继续游戏、结算后再来一局是否顺畅。

### C. 技能（20 个）
1. 每个技能的定位（单体/清群/控场/爆发/召唤/持续）是否清晰？哪些技能定位重叠或明显弱势？
2. 4 槽位下，是否存在「必带」与「永远不选」的技能？给出名单与理由。
3. 技能升级（Lv）收益是否匹配其抽卡权重？
4. 技能与黑科技的兼容限制是否合理（例如蓄能脉冲现在可装增大）？

### D. 黑科技（18 个）
1. 逐个评估：独立价值、叠加上限、与哪些技能/黑科技形成强组合；列出 T0/T1/T2/陷阱选项。
2. 重点检查：多重+散射+分裂+连锁+echo+落雷 的弹道/触发爆炸；吸血+击杀回血+反伤 的续航上限；冷却缩减+echo 的乘算；增大/范围 对命中与视觉的影响。
3. 是否存在无限循环、性能爆炸（弹体数量）、数值溢出、必选组合？
4. 描述/数值是否足够让玩家理解「升到 Ⅱ/Ⅲ 后具体强多少」？

### E. 道具（T1~T3）
1. T1/T2/T3 的强度梯度是否成立？传说是否过强/过弱？
2. 负收益道具（血契、低血强化、极简专精、刷新省钱等）是否值得选？风险回报是否清晰？
3. 道具与黑科技的乘区是否重复/冲突？哪些道具是「拿到就赢」或「永远不拿」？
4. 商店价格/掉落来源是否匹配稀有度？

### F. 组合与极端情况
1. 给出 5~8 套强势组合与 3 套弱势组合，说明原理。
2. 找出可能的破坏性组合（无限回血、无限子弹、永冻、秒 BOSS、刷金币）。
3. 对每个破坏性组合给出「限制哪一层」的建议（数值上限、触发 CD、叠加上限、收益递减）。
4. 评估组合多样性：是否只有一条最优解？

### G. 难度与数值
1. 结合 20 波样本，判断普通难度是否过易；给出每 5 波的目标承伤/血量/击杀区间。
2. 5 档难度倍率是否合理？地狱 1.75/1.55/1.95 是否足够，还是靠规则而不是数值？
3. 怪物成长（每波 HP +42%、伤害 +20%）与玩家成长（升级/黑科技/道具）是否匹配？在哪些波次出现断崖？
4. BOSS 三技能（弹幕/冲锋/砸地）与精英（扇形弹/冲锋）是否提供足够反制与差异？
5. 每波回满 + 低承伤是否让「防御/回复」类构筑失去意义？
6. 商店经济：金币收入、价格、刷新（+3/次）、锁定是否形成有效取舍？
7. 给出具体数值调整建议（旧值 → 新值 → 预期效果）。

### H. 边界与健壮性
1. 升级弹窗打开时死亡/暂停/切后台/连点；选黑科技进入安装屏后返回；连续升级。
2. 商店中升级、波末升级、暂停中升级。
3. 继续游戏恢复（生命/技能/商店/升级卡）是否可能重复奖励或丢档。
4. 历史 50 局上限、runId 幂等、坏档处理。
5. 微信真机：安全区、胶囊、底部手势、剪贴板隐私。

## 输出格式（必须遵守）

1. **结论摘要**（10 行内）：最严重的 3 个问题 + 最值得保留的 3 个设计。
2. **问题清单**：表格，列 = ID / 模块 / 严重度(P0~P3) / 证据 / 问题 / 影响 / 建议（具体到数值或交互）。
3. **平衡表**：技能、黑科技、道具分别给 T0/T1/T2/陷阱分级与理由。
4. **组合矩阵**：强势组合、破坏性组合、限制方案。
5. **难度曲线**：按波次给目标区间与调整建议（含具体数值）。
6. **UI 修改清单**：按页面给「改什么/改成什么」。
7. **Top 10 优先改动**：按投入产出排序。
8. **需要补充的数据/实验**：列出无法从材料判断、需要真机或埋点验证的点。
9. **不要**输出泛泛而谈的「增加打击感/优化体验」，每条建议必须可落地。

# UI 专项验收清单

DeepSeek 完成后逐项勾选。未实际验证的项目不得打勾。

## 素材与授权

- [ ] 只获取了免费公开的单独素材包，没有付费礼包依赖。
- [ ] 主 UI 风格已选择，其他包没有未经规划地混合。
- [ ] 实际使用的素材有名称、来源 URL、许可证和文件路径记录。
- [ ] 原始素材保留，项目处理后的素材没有覆盖原件。
- [ ] 字体来源、许可和中文覆盖已确认。
- [ ] 没有把网站预览图或线框截图当作正式游戏素材。

## 视觉一致性

- [ ] 面板边框、按钮、卡片、标题栏、状态条具有统一像素风格。
- [ ] 主按钮、普通按钮、禁用/选中状态清楚。
- [ ] 没有明显模糊、双线性缩放、边框拉伸或不匹配的像素密度。
- [ ] 字体清晰，中文无缺字、乱码、溢出和重叠。
- [ ] 现有角色和技能素材自然融入界面，没有被无意义装饰压住。

## 页面与交互

- [ ] 主菜单可正常进入已有的角色选择/游戏入口。
- [ ] 角色选择使用现有角色素材，选中状态明确。
- [ ] 战斗 HUD 不遮挡主要战斗区域，真实数据显示正确。
- [ ] 四个技能槽（若当前玩法有四技能）与实际技能匹配。
- [ ] 升级三选一卡片尺寸一致、说明可读、点击后执行实际升级。
- [ ] 暂停/恢复行为正确，底层 UI 不会被误触。
- [ ] 商店、结算、图鉴等现有页面可正常操作。
- [ ] 未实现的功能没有用假按钮伪装成已完成。

## 适配与运行

- [ ] 使用项目原有 Cocos 架构实现，不是独立 HTML 替代品。
- [ ] 在实际运行环境测试横屏和安全区域。
- [ ] 测试常规 16:9 画面与至少一种不同宽高比的布局表现（环境允许时）。
- [ ] 关键触控区域尺寸适合手机。
- [ ] 弹窗打开/关闭与页面切换没有异常。
- [ ] 实际项目构建/运行测试结果已记录。
- [ ] 提交主菜单、角色选择、战斗 HUD、升级三选一、商店/道具和结算的真实截图。

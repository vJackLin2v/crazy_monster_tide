### 2.1 ★ 锁与购买的触控互斥（本里程碑重点）

**问题**：`lockHit` 是商品行的**子节点**，Cocos 的 `TOUCH_END` 会**冒泡到父节点**——
只写 `onTap(hit, onLock)` 的话，点锁会**同时**触发整行的 `onBuy`。

**修法**：锁按钮单独监听并在回调里 `e.propagationStopped = true`，不再走 `onTap`：

```ts
hit.on(Node.EventType.TOUCH_END, (e: EventTouch) => {
  e.propagationStopped = true;      // ← 关键：拦住冒泡，行收不到这次点击
  Sfx.sfx('click', 0.45, 40);
  onLock(i);
}, hit);
```

**实测证据**（真实鼠标点击，不是调用函数）：给到 999 金币后开店——

```text
BEFORE   gold=999  row0(eliteDmg_s, price 17) sold=false locked=false
点锁     坐标 (324,136)
AFTER    gold=999  row0 sold=false locked=true      ← 只锁定，没扣钱
点主体   坐标 (120,136)
AFTER    gold=982  row0 sold=true  locked=false     ← 扣款 = 17 = 价格
✅ 点锁只锁定不购买 = true
✅ 点主体才购买（扣款=17，价格=17）= true
```

> 之前用 6 金币测过一次，购不买得起都失败，等于没测出来——**必须给足金币**才算验证。

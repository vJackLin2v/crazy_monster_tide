# 免费 UI 素材与参考链接

目标：全部 0 元获取；优先 CC0；只获取官方页面公开的免费单包，不购买合集。

## 1. 主候选：Kenney Pixel UI Pack

官方页面：https://kenney.nl/assets/pixel-ui-pack

官方页面当前说明：750+ 个文件，CC0。包含面板、按钮、光标/指针、状态条、勾选框、滚动条等组件；有独立九宫格 PNG 和 Sprite Sheet。下载时可选择 `Continue without donating...`（继续，不捐赠）。

适用：
- 通用像素面板和窗口。
- 普通/选中/禁用按钮。
- 生命/经验等状态条。
- 卡片、弹窗与控件底板。

建议：优先从这套选主 UI 零件，但不要因为文件数量多就全部使用；挑一个主视觉系列，制作小型资源样板后再批量引用。

## 2. 第二候选：Kenney UI Pack - Pixel Adventure

官方页面：https://kenney.nl/assets/ui-pack-pixel-adventure

官方页面当前说明：500+ 个文件，CC0；有单张 PNG 及精灵表。风格更偏冒险游戏 UI，可作为 Kenney Pixel UI Pack 缺失组件的候选，也可以作为整体替代方案。

注意：如果主 UI 选了第一套，只把此包用作补件；两个包不要无规划混拼。如果需要从第二套取边框，先确认线宽、阴影、外框色和像素密度与主包一致。

## 3. 完整页面参考：Foozle Critters Pixel UI

官方页面：https://foozlecc.itch.io/critters-pixel-ui

官方页面当前说明：Name your own price；ZIP 约 3.1 MB；包含 HUD（生命/体力、资源计数、经验条）、主菜单、背包、商店/商人界面、技能图标和部分字体，并附带 Aseprite 源文件；CC0，可用于商业项目且无需署名。

用法：
- 主要学习怎样把零件组织成完整的 HUD、菜单、背包和商店。
- 需要时可以选少量与主包风格匹配的组件，但不能不检查风格就把整套混入。
- itch.io 获取时如出现自定价格，填 0 元即可；不要进行捐赠或付费。

## 4. 可选补充：Kenney UI Pack - Adventure

官方页面：https://kenney.nl/assets/ui-pack-adventure

官方页面当前说明：130 左右的 UI 组件，CC0。它偏传统冒险 UI，可用于检查缺少的按钮、滑块、面板组件。仅在与主包匹配时使用。

## 5. 字体候选（必须单独审查）

Fusion Pixel Font：https://github.com/TakWolf/fusion-pixel-font

不要因为是开源项目就自动认为字体每个文件都适用。使用前核对仓库实际许可证、字体文件、中文字符覆盖、显示效果和项目使用场景。优先用已有且清晰的游戏字体，只有确实缺中文字体时才增加依赖。许可证文本按要求随项目保留。

## 7. 免费下载操作

### Kenney

1. 打开官方资源页。
2. 点击下载。
3. 如出现捐款选择，使用 `Continue without donating...`。
4. 下载单个资源包，不要点击购买 All-in-1 bundle。
5. 解压后检查许可证文件和原始资源结构。

### itch.io

1. 打开 Foozle 官方资源页。
2. 点击 `Download Now`。
3. 若出现 Name your own price，价格输入 `0` 后获取。
4. 下载 ZIP，解压并检查 LICENSE/README。

如果 DeepSeek 使用的执行环境不能访问互联网或不能通过页面下载，必须报告需要用户手动下载的包名和准确 URL；不能假称已下载，也不得绕过平台访问限制。

## 8. 实际使用记录模板

DeepSeek 应在项目内建立 `docs/ui-redesign/asset_usage_manifest.md` 或遵循项目现有的素材记录规范，至少记录：

| 字段 | 内容 |
|---|---|
| 资源包 | 官方名称 |
| 来源 URL | 原始官方页面 |
| 实际下载 ZIP | 文件名 |
| 许可证 | CC0 / 其他实际许可证 |
| 实际使用文件 | PNG、Sprite Sheet、字体等文件名 |
| 项目路径 | 资源落入的相对路径 |
| 用途 | HUD、面板、按钮、卡片等 |
| 修改记录 | 裁切、调色、九宫格、尺寸调整等 |
| 备注 | 署名要求或未解决问题 |

只有实际检查过许可证并实际使用的文件，才能标记为“已核实”和“已使用”。

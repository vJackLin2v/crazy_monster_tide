# 《像素共鸣：远征》UI 改造交付包

这个目录是给 DeepSeek 开发 Agent 使用的 UI 专项任务包。它不是游戏运行代码，也不是最终 UI 素材包；它提供的是明确的页面布局、离线线框参考、免费素材地址和可执行的开发任务。

## 目录内容

- `01_直接交给DeepSeek的启动提示词.md`：复制此文件全文给负责开发的 DeepSeek。
- `02_UI页面布局与尺寸规范.md`：逐页布局、1280×720 参考坐标、控件尺寸和适配要求。
- `03_免费UI素材与参考链接.md`：免费 UI 下载地址、授权说明、素材选择规则。
- `04_UI布局线框参考.html`：双击即可在浏览器打开的离线页面线框，顶部可以切换不同页面。它是布局参考，不是最终美术图。
- `05_验收清单.md`：验收 UI 是否真的落地并在 Cocos 中运行。

## 放到哪里

将 ZIP 解压到《像素共鸣：远征》的 **Cocos 项目根目录**，也就是与 `assets/`、`settings/`、`package.json` 同级的位置。解压后应出现：

`<项目根目录>/docs/ui-redesign/README_请先看.md`

如果项目根目录没有 `docs/`，可以直接把 ZIP 解压到根目录，让压缩包中的 `docs/ui-redesign/` 自动创建；不要把整个任务包放进 `assets/`，因为这些是开发文档，不是游戏资源。

## 怎么交给 DeepSeek

1. 先确认 DeepSeek 当前打开的是《像素共鸣：远征》的项目根目录。
2. 把本目录里的 `01_直接交给DeepSeek的启动提示词.md` 全文复制到 DeepSeek。
3. 让她先读取 `docs/ui-redesign/` 里的全部文档和线框 HTML，然后按提示词开始改造当前工程。
4. 如 DeepSeek 无法联网下载素材，让她报告准确的官方链接和需要你手动下载的文件名；不能假装已下载或编造授权信息。

## 重要

素材网站可能更新页面或文件。所有素材应从文档列出的官方来源获取，并在实际提交前再次检查授权。线框里的占位文字和矩形只用于说明布局，开发时必须使用实际 UI 组件以及游戏中已经存在的角色、怪物、技能和道具资源。

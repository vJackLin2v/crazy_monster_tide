# UI 视觉规范 v1.0（视觉升级 · 已冻结）

> 状态：🔒 **FROZEN v1.0** ｜ 冻结日期：2026-10-29 ｜ 适用范围：全站 UI（11 个界面）
> 上位文档：`docs/ui/ui-spec-approved.md`（v1.5 起引用本文件作为**颜色/字号/组件**的唯一来源）
> 本文替代 v1.3 规格里的色板与字号表；**页面布局**仍以 `ui-spec-approved.md` + 各里程碑规格为准。

---

## 1. 风格定位

**暗夜像素奇幻 + 怪潮压迫感 + 技能构筑科技感。**

角色、怪物、技能特效是画面主角；UI 是"有质感的游戏界面"，不是后台管理面板。
视觉关键词：深蓝夜色 / 清晰像素描边 / 分层面板 / 橙金主操作 / 青色选择态 / 紫色稀有 / 绿色正向 / 红色危险。
**克制**：装饰只出现在角标、分隔线和选中态上，不在每张卡上堆金边/光效。

| 普通面板 | `#1E2A46` | `COL.bg2` | 普通容器，不能与背景融为一体 |
| 次级面板 | `#263653` | `COL.bg3` | 列表行、内层卡片 |
| 面板描边 | `#34496E` | `COL.edge` | 普通边线；**不再用纯黑粗框** |
| 高亮描边 | `#617DA8` | `COL.edgeHi` | 悬停/焦点/面板内沿，仅局部使用 |
| 唯一主操作色 | `#FFA84B` | `COL.accent` | 开始 / 继续 / 购买 / 下一波 / 确认推进 |
| 主操作暗部 | `#C97A2A` | `COL.accentD` | 主按钮硬投影、按下态 |
| 选中/科技 | `#61DCE7` | `COL.select` | 被选中的卡、可安装槽、模块状态 |
| 正向/回复 | `#88D6BC` | `COL.mint` | 正向天赋、回血、提升数值 |
| 稀有 | `#B68AFF` | `COL.purple` | 高级道具、稀有奖励 |
| 危险/负向 | `#E04060` | `COL.red` | 负面天赋、退出确认、失败、危险状态 |
| 正文 | `#F7E9E0` | `COL.cream` | 标题和主要信息 |
| 次级文字 | `#A8B5CD` | `COL.dim` | 说明、标签、次要数据 |
| 禁用文字 | `#6D7892` | `COL.dim2` | 禁用状态；仍需可辨认 |
| 遮罩 | `rgba(6,10,22,.72)` | `COL.mask` | 模态背景 |

> ⚠️ 面板描边（#34496E）与文字描边（#0A0E1A）是**两个变量**：前者给容器，后者给 LabelOutline。
> 混用会让正文在深底上失去对比（旧实现共用 `COL.line`）。

## 3. 字号阶梯（冻结）

| 档 | 字号 | 用途 |
|---|---|---|
| 主标题 | 38–42px | 主菜单游戏名 |
| 页面标题 | 22–26px | 各页标题 |
| 卡片/商品/技能名 | 14–16px | 卡片主信息 |
| 主要说明 | 12–13px | 天赋、属性值、按钮字 |
| 次要说明 | 11–12px | 效果描述、状态 |
| 极次要 | 10px | seed、计数、元数据；**不得承担关键玩法说明** |

正文可换行，但必须给足 Label 高度（`h`），禁止用 CLAMP 静默裁掉关键描述。
字体沿用系统字体（原因见 `asset_usage_manifest.md` §6）；不强行替换像素中文字体。

## 4. 组件规则

| 组件 | 规则 |
|---|---|
| 面板 | 三层：全屏背景 → 主要浮层面板 → 内嵌槽/数据行。不要把每块文字都包面板 |
| 面板底 | `#1E2A46`，描边 `#34496E`，内沿高光 `#617DA8`（仅 1px） |
| 主按钮 | `#FFA84B` 底 + `#2B1D00` 深字 + 2px 深色边 + 5px 硬投影；高 52–56 |
| 次按钮 | `#263653` 底 + 正文色字 + 描边；高 44–50 |
| 危险按钮 | `#E04060` 底 + 白字 |
| 禁用 | 专用素材 `btn_disabled` + 文字 `#6D7892` |
| 槽位 | 空槽 `#0D1732` 内凹；已装 `#1E2A46` + 图标；选中 `#61DCE7` 描边 |
| 进度条 | 高 10–18；底槽 `#0D1732`；生命 `#88D6BC→#3E9E7C`（正向色），经验 `#617DA8→#3E5B8A` |
| chip | 10–11px，描边=类别色，最多两行；类别必须同时有文字 |
| 卡片类别 | 新技能=金 `#FFC467`｜技能强化=绿 `#88D6BC`｜黑科技=青 `#61DCE7`｜道具=紫 `#B68AFF`｜属性=蓝 `#6E8FD0` |
| 选中态 | 底色提亮 + 类别色描边 + 形状标记（勾选/角标），**不只改文字颜色** |
| 间距 | 4 / 8 / 12 / 16 / 24 |
| 边距 | 左右 12；内容宽 336 |
| 热区 | 有效热区 ≥44×44；相邻可点区不重叠 |
| 像素 | 全部 NEAREST；角色与小图标整数倍缩放；九宫格四角不拉伸 |
| 阴影 | 只用硬像素投影/内沿，不用模糊阴影；发光只给选中、稀有和关键战斗状态 |

## 5. 坐标与适配

- 画布 360×640，原点左上、y 向下；落地时转 Cocos 节点坐标。
- 顶部一律 `y = S + 距顶`；底部一律 `y = VH - B - 距底`；**不得把 640 当成实际可视高度**。
- 内容宽度 `x = 12 … 348`。
- 验收视口：360×640 / 390×844 / 412×915；**微信真机安全区属于未验证项**。

| `accent #f5a623` | `#FFA84B` | 主操作 |
| `accentD #b8790c` | `#C97A2A` | 主操作暗部 |
| `mint #8bd63a` | `#88D6BC` | 正向/回复（经验条改用蓝） |
| `red #e8452f` | `#E04060` | 危险 |
| `purple #9b63d6` | `#B68AFF` | 稀有 |
| `cream #ffffff` | `#F7E9E0` | 正文 |
| `dim #b9c0cf` | `#A8B5CD` | 次要文字 |
| `dim2 #7c8496` | `#6D7892` | 禁用文字 |

**同步动作**：
1. `cocos/assets/resources/ui/kenney/*.png` 用 `tools/art/gen_ui_kit.py` 按新色板重新生成（meta 不重建，UUID 不变）。
2. `ui/Tokens.ts` 更新为上面的值，并新增 `edge / edgeHi / select / inkLine`。
3. `UIKit.ts` 的面板回退与文字描边分别用 `edge` / `inkLine`。

## 6.5 元页面（图鉴 / 成就 / 设置）

| 页面 | 结构 | 数据 | 交互 |

## 7. 验收方式

- 每个里程碑在 `screenshots/ui-visual-upgrade/<milestone>/` 输出新截图，**不覆盖** `screenshots/ui-redesign/` 基线。
- 截图必须来自真实运行的 Cocos 构建产物；写明"浏览器构建截图"。
- 微信真机必须单独记录设备/系统/开发者工具版本，未测就写"未验证"。

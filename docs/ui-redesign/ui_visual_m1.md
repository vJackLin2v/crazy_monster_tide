## 1. 全局：色板与素材

| 项 | 改动 |
|---|---|
| `ui/Tokens.ts` | 换新色板；**面板描边 `edge` 与文字描边 `inkLine` 拆成两个变量**（旧实现共用 `line`） |
| `ui/UIKit.ts` | 文字描边用 `inkLine`、容器描边用 `edge`；按钮/面板回退同步 |
| `tools/art/gen_ui_kit.py` | 19 张九宫格按新色板重生成（**meta 不重建，UUID 不变**）；外沿由纯黑改 `#0A0E1A` |

> 影响面：色板是全局的，**所有页面**都会继承新配色；但 M1 **没有改**其它页面的布局与交互。

## 2. 主菜单 `buildMenu()`

| 区域 | 实现 | 数据/交互 |
|---|---|---|
| 背景 | `home-bg-360x640` cover 缩放（不拉伸）；上下各 8 段等宽暗角（像素风不用模糊） | 静态 |
| 标题 | `疯狂怪潮` 40px，`y = S+60`；副标题 10px 橙色加宽字距，`S+100` | 静态 |
| 主视觉 | `CHARS[0]` 立绘（`Assets.loadPortrait`）整数倍放大到高 120~138，`x` 补 +7 抵消剑的视觉偏移；失败 → idle 首帧；再失败 → 静默不显示（**不放彩色占位块**） | 只读 |
| 卖点条 | 3 个 100×30 信息块（`panel_soft`）：`4 个主动技能` / `黑科技构筑` / `20 波挑战`，10px | 静态，**不可点** |
| 主 CTA | 276×56 橙色，中心 `S + (VH-S-B)×0.655`（640 下 ≈422） | `onStart()` → 角色选择 |
| 次 CTA | 276×46，主 CTA 下方 60 | `onHowto()` → 玩法说明 |
| 页脚 | 10px `dim2`，离底 26：`本局种子 xxxx · 同种子奖励相同` | 读 `seed` |

**适配**：标题/页脚分别锚顶、锚底；卖点条与 CTA 按可视高度比例；角色舞台取剩余空间并居中。

## 3. 角色选择 `buildCharSelect()` + `CharLayout`

| 项 | 旧（v1.3） | 新（M1 v1.4） |
|---|---|---|
| 卡片 | 106.7×124 | **106.7×90** |
| 立绘 | 78×90（占满卡面） | **52×60**（整数倍，≥ 卡高 2/3） |
| 姓名 | 11px | **12px**，正文色 |
| 选中态 | 青框 + 橙字 | **青框 + 提亮底 + 右上角勾选徽标** |
| 详情 | 名称/正负天赋/技能行/一行属性字符串 | **四段式**：名称 20px、＋/－ 色标 + 天赋、初始技能槽（32 图标 + 名称 + 「初始技能」标签）、**3×2 属性网格** |
| 属性数据 | 只显示角色显式写过的字段 | `freshStats(ch)` 的**开局真实六项**：攻击×/移速/生命/暴击/回血/拾取（只读，不改玩法） |
| 布局 | 网格顶边固定 | 网格+详情**作为一个整体块**在「标题条 ~ 按钮」之间垂直居中（矮屏几乎不偏移，长屏不把空白堆在一侧） |

**测试同步**（`tests/run.ts`）：立绘期望 78×90 / 51×75 → **52×60 / 34×50**；重叠断言改用属性块高度 `dr.stat.h`。

> 说明：图鉴与成就是**新增功能**，按用户明确要求加入；都只读现有数据或累计计数，不改战斗、掉落、经济。

## 5. 未验证 / 风险

1. **微信真机安全区未测**（浏览器里 `getSafeAreaRect` 返回全屏，只有常量兜底）。
2. 主视觉立绘只在**默认角色**（铁拳骑士）上验证；换角色做主视觉属于后续需求。
3. 立绘完全缺失时（portrait + idle 都失败）只验证了代码路径，没有单独截图。
4. 色板改动会影响 HUD / 商店 / 结算等页面观感，**这些页面本轮未重新验收**（属 M2–M5）。

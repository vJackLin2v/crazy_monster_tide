## 我要你做什么

这套视觉系统目前处在什么水平（原型 / 可用 / 合格上线 / 有辨识度）？最突出的优点和最突出的问题各 1 个。

### ② 逐页问题（重点，按严重度排序）
对以下 16 屏逐屏看：主菜单 / 玩法说明 / 角色选择 / 战斗 HUD / 升级三选一 / 商店 / 构建抽屉 / 黑科技安装 / 技能替换 / 二次确认 / 结算（通关）/ 结算（阵亡）/ 图鉴 / 成就 / 设置 / BOSS 波。
每屏只写**最重要的 1–3 条**，格式：

```
[页面] 问题描述
- 严重度：P0（影响可用性/理解）/ P1（明显不专业）/ P2（打磨项）
- 证据：截图里的具体位置，或代码里的文件:行号
- 建议：具体怎么改（尺寸/颜色/文案/层级）

```

### ③ 视觉系统层面
色板（15 色）、字号阶梯、间距、九宫格、描边（容器描边和文字描边已拆开）、状态双通道（颜色+形状/文字）——这套系统有没有**内在矛盾**或**明显缺失的层级**？如果只能改 3 个令牌，改哪 3 个？

### ④ 竖屏 + 微信小游戏专项
在浏览器里正常、但**真机可能出问题**的地方：
- 安全区（刘海/手势条）处理
- 触控热区（我按 ≥44 做的，但有小按钮如 32 视觉 + 44 热区）
- 字号在真机上的可读性（最小 9–10px 的地方）
- 性能（顶部承载板、残血多层发光都是 Graphics 绘制）
- 微信小游戏的点击穿透 / 震荡反馈

排优先级，每条写清：做什么、为什么先做它、预期收益、验收标准。

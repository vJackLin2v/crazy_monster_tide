## 4. 未验证 / 风险

1. **微信真机安全区**仍未测 —— 这是从 M1 一路留下的唯一硬缺口（S/B 仍是常量兜底 28/10）。
2. 自动跑图的"走位"是机械绕圈，不代表真实操作手感；它的作用是**跑流程 + 看稳定性**，不是可玩性验收。
3. 跑图为保证能站在 BOSS 面前截图，把 `maxhp/hp` 拉到 99999（**仅测试用**，未改任何数值表）。
4. 玩法说明页步骤块下方仍有一片留白（4 步就这些内容，不做填充）。
5. 结算页 4 行构筑是"最多显示"：技能超过 4 个时（无尽/替换）只列前 N 行，未做滚动。

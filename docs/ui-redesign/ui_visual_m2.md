## 2. 相对旧版的具体改动

| 项 | 旧 | 新 | 为什么 |
|---|---|---|---|
| 顶部可读性 | 数字直接浮在战场上 | 加 6 段渐隐承载板（最高 S+92） | 怪多/特效亮时数字仍可读，且不侵占中央战斗区 |
| 倒计时 | 24px | **26px** | 1 秒内能读到"还剩几秒" |
| 暂停键 | 34×34，中心 S+81 | **36×36，中心 S+29** | 旧位置与 BOSS 血条在 y 上重叠（BOSS 时互相压） |
| BOSS 血条 | 居中 y≈S+114，与暂停键重叠 | 名字 S+64 / 血条 S+80，宽 336 | 与暂停键、波次信息彻底错开 |
| 金币 | 15px 数字 | **14px + 16 图标成组** | 更像"资源标签"而不是漂浮数字 |
| 经验条 | 156×14 | **156×12** | 与 HP 拉开层级 |
| 残血态 | 无 | **<25% 珊瑚红字 + 柔和外发光**（用户反馈：红框太"框"，改泛光） | 危险要看得出来，但不要硬边框、不要过饱和；静态不闪烁 |
| 冷却遮罩 | alpha 140 | **alpha 120** | 冷却中仍能辨认是哪个技能 |

## 3.5 残血态：红框 → 柔和外发光（用户 2026-10-29 反馈）

- **做法**：血条**下面**垫 6 层低透明度圆角矩形（半径逐层外扩 5.4→17.4px，alpha 24→10，
  颜色 `rgb(198,92,112)` 偏灰的暗红），等价于"柔和阴影/泛光"，纯像素绘制、不用模糊。
- **两个坑**：
  1. 发光层如果建在血条**之后**，会盖在血条上把它糊成灰块 → 必须建在血条**之前**（渲染顺序）；
  2. 不要在内侧再叠暖光层，否则填充色被冲淡。
- 文字颜色同步从 `#E04060` 换成 `#F07680`（珊瑚红，不刺眼）。
- 可调参数集中在 `Hud.sync()` 的 `pad / alpha / color` 三处；截图见 `m2/360x640-hud-lowhp-boss.png`。

## 4. 未验证 / 风险

1. **微信真机安全区未测**（S/B 仍是常量兜底）。
2. 受击闪屏 / 精英泛光 / 屏震的"幅度上限"本轮没有量化测（沿用既有实现）。
3. 高密度怪潮（200+ 同屏）下顶部承载板对可读性的提升，只做了静态截图，没有做动态对比。

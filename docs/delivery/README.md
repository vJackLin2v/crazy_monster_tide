## 3. 关键数值现状

- 刷怪：`interval = max(0.34, 0.62 - 0.016×wave)`，`batch = min(3, 1+floor(wave/4))`，峰值 8.82/s
- 同屏：软上限 40、硬上限 60，超限减速 1.6×
- 怪物成长：HP +18%/波，伤害 +10%/波
- 模块：单模块上限 3；`_2` 合成效果 ×1.6、容量算 2；吸血 4%、荆棘 6%
- 角色：6 个，初始技能 = 回旋刃 / 奥术 / 灵能箭 / 冰晶矛 / 陨石 / 圣光弹

## 更新记录（v11 · 2026-10-30 21:35）

**构建抽屉（4 页全部重排）**
- 技能页：丢弃按钮移到行最右，技能名/描述自动缩宽，不再压字；
- 黑科技页：改为手动裁剪渲染（只显示完整落在视口内的行，底部留 40px），解决半截行压在主菜单按钮上；
- 道具页：可查看全部道具并滚动；同名道具合并成一行显示 xN；
- 属性页：去掉绿色=高于基础的图例，改为一行一属性（名称左、数值右对齐），默认列出全部属性并可滚。

**滚动**
- 三个列表页共用 ui/ScrollView.ts：Mask(GraphicsRect) + 全局 input + 节点事件双通道；
- 新增惯性：松手后按每帧 x0.90 衰减滑行，撞边界立即停（实测松手后再滑行约 144px）。

**黑科技分级（可无限合成）**
- 3 个 N 级合成 1 个 N+1 级，等级无上限（为无尽模式准备）；
- 效果 = 1 + 0.6 x (等级-1)：II=x1.6、III=x2.2、IV=x2.8，线性不爆炸；
- 容量：1 级占 1 份，2 级及以上占 2 份；
- 名字带罗马数字（巨大 / 巨大 II / 巨大 III）；
- 只认同名同级：2 个 I + 1 个 II 永远合不了。

**平衡**
- 吸血每份 4% 改为 3%；
- 所有自我回血（吸血 + 击杀回血）走统一入口 healPlayer()，合计每秒最多 8 HP；
- BOSS 减速单独封顶 30%（普通怪仍 35/45/55%）。

**测试**
- 182 条用例全绿（新增：分级合成 5 条、BOSS 减速 2 条、回血预算等）。

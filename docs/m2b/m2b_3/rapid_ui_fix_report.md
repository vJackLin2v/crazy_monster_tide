# rapid UI 文案修正报告

## 1. 原公式与实际公式

实际战斗计算（未改）：

    rapidPer = stats.modCdrMul ? 0.88 ^ stats.modCdrMul : 0.88
    cd *= rapidPer ^ rapid

rapid 等级参数：

- Lv.1：e = 1
- Lv.2：e = 1.6
- Lv.3：e = 2.2
- 多个 rapid 模块时，e 会相加；UI 单项按单个模块等级显示。

原 UI 公式（错误）：

    冷却缩减 = 1 - 0.88 ^ e

没有乘入 modCdrMul；因此法师三级都显示普通角色数值。

新 UI 公式（与 SkillCalc 一致）：

    冷却缩减 = 1 - 0.88 ^ (modCdrMul × e)

## 2. 普通角色三级核算

modCdrMul 未设置，rapidPer = 0.88：

| 等级 | e | 倍率 | 缩减 | UI |
|---|---:|---:|---:|---|
| Lv.1 | 1 | 0.88 | 12.0% | 冷却 -12.0% |
| Lv.2 | 1.6 | 0.815027524 | 18.4972% | Lv.2 · 冷却 -18.5% |
| Lv.3 | 2.2 | 0.754852119 | 24.5148% | Lv.3 · 冷却 -24.5% |

普通三级期望值：12.0% / 18.5% / 24.5%。

## 3. 法师三级核算

modCdrMul = 1.25，rapidPer = 0.88^1.25 = 0.852321297：

| 等级 | e | 有效指数 | 倍率 | 缩减 | UI |
|---|---:|---:|---:|---:|---|
| Lv.1 | 1 | 1.25 | 0.852321297 | 14.7679% | 冷却 -14.8% |
| Lv.2 | 1.6 | 2.00 | 0.774400000 | 22.5600% | Lv.2 · 冷却 -22.6% |
| Lv.3 | 2.2 | 2.75 | 0.703602459 | 29.6398% | Lv.3 · 冷却 -29.6% |

法师目标值 14.8 / 22.6 / 29.6，与当前 SkillCalc 公式一致。

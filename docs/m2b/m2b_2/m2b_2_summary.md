# M2-B.2 审查总结

## 总体结论

- rapid：法师 UI 文案错误；普通角色正确；当前战斗公式未发现执行错误。
- 商店兼容性：不是“买了就废”的逻辑缺陷；是可保留、可未来安装、可出售的长期构筑选择，但缺少兼容提示且与奖励池口径不一致，属体验问题。
- 本轮未修改任何游戏源码/数值。

## rapid

- 普通 Lv.1/2/3：12.0 / 18.5 / 24.5，UI 正确。
- 法师 Lv.1/2/3：14.8 / 22.6 / 29.6，UI 仍显示 12.0 / 18.5 / 24.5，错误。
- 错误位置：game/ModuleText.ts rapid 分支；data/Modules.ts MODULE_NUMS.rapid（升级卡）。
- 额外：SkillCalc 注释写 0.85，实际 0.8523；这是设计语义待确认，不直接改公式。
- 优先级：P2（只影响显示与构筑判断；不影响战斗）。
- 是否需要改代码：需要改 UI 文案；不需要改公式（除非设计确认）。

## 商店兼容性

- 模块先入 modsBag，不自动安装。
- 未安装模块占 totalMods 配额，但可保留。
- 获得兼容技能后可安装；可出售/合成；技能替换会把模块退回背包。
- 商店 makeShopItem 不检查兼容；奖励池 rollRewards 检查。
- 100 个固定种子、meteor-only 模拟：189 个模块货位中 98 个（51.9%）当前不可安装。
- 不是 P0：没有金币消失/物品丢失/死状态。
- 是 P1：影响购买决策，UI 未提示；也可视为 P2 提示问题；本轮建议 P1。
- 是否需要改代码：建议只做提示/标签；是否过滤商品需产品决策，不能直接改随机池。

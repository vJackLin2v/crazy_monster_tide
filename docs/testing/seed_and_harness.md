# 固定种子与 Test Harness

## 1. 为什么

肉鸽游戏的随机性必须**可复现**，否则 bug 无法定位、回归无法比对、平衡无法验证。

## 2. 规则 `[定]`

- 所有随机（奖励抽取 / 怪潮生成 / 地图生成 / 暴击）统一走**同一个 RNG 实例**。
- 一局开始时确定 **RunSeed**；局内所有随机从 RunSeed 派生（禁止直接调用全局随机）。
- 测试可传入指定 seed，得到**逐位一致**的结果。
- 日志必须打印 seed，便于复现。

## 4. 反例（禁止）

- 在核心玩法里到处直接调用全局随机；
- 用时间戳做种子（不可复现）；
- 测试里为了过而硬编码结果。

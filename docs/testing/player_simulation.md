# 玩家模拟测试规范（人类式 E2E）

## 1. 原则

E2E 要模拟**真人怎么玩**，不是点一遍所有按钮：

- 有停顿（人不会每 16ms 点一次）；
- 有误操作（点错卡片、拖过头）；
- 有中断（切后台 / 息屏 / 断网）；
- 走真实视口（375x812 / 390x844 / 412x915）。

## 2. 必测场景清单（最小集）

| # | 场景 | 关注点 |
|---|---|---|
| 1 | 完整一局：选人 → 地图 → 战斗 → 升级 → 结算 | 主流程不断链 |
| 2 | 固定 seed 复现同一局 | 随机可复现 |
| 3 | 动态摇杆：拖动 / 松手 / 拖出边界 | 输入鲁棒性 |
| 4 | 升级 3 选 1：快速连点 / 选到满技能 | 边界与空奖励 |
| 5 | 行为模块：装到不兼容槽位 / 卸下 / 搬家 | 兼容性判定 |
| 6 | 战斗压力：怪潮峰值 | 性能与可读性 |
| 7 | 三档竖屏视口 | 布局与热区 |
| 8 | 中断恢复：切后台再回来 | 状态一致性 |

## 3. 产出物

每组场景必须留下：**截图（真实视口）/ trace / seed / 结论**，并写入汇报。

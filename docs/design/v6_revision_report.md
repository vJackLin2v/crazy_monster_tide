## 四、测试写法约束（新增）

expansion_acceptance_criteria.md 增加"测试写法约束"：

1. 禁止用配置值当预期值（例如 expect(actual).toBe(config.damageMultiplier)）；
2. 每条新机制至少断言四类事实：实际伤害、触发次数、治疗量、递归次数；
3. 预期值必须写独立常量（手工推导）；
4. 哨兵必须有"击杀不回血"与"命中可吸血"两条独立用例。

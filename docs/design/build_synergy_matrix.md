# 构筑协同矩阵（build_synergy_matrix）

> 现有 16 技能 × 18 黑科技 × 70 道具，加上本批新增内容。这里给 12 套**玩法不同**的构筑。

## 1. 协同判定规则（矩阵用）

- 技能提供形态：弹体 / 脉冲 / 区域 / 链式 / 新形态（环绕/陷阱/召唤/蓄力）；
- 黑科技改形态：加弹、改轨迹、加触发（onhit）；
- 道具改决策：要不要冒险、要不要省钱、要不要专精。

## 4. 可能过强的组合（需要在评审确认）

1. **专注核心 + echo + multi**：24 步规则已定——专注核心按技能伤害乘区生效，**echo 重放同样享受**（同属该技能伤害），但 echo **不计入蓄势/施法次数**；不再保留"对 echo 不生效"的旧说法；
2. **overcharge + echo**：echo 重放是否计入"第 4 次施法"？应**不计入**，否则蓄势会每 2 秒触发；
3. **killblast + 高密度怪**：击杀爆炸不再连锁，所以安全；
4. **shieldonhit + thornmail**：护盾 + 反伤可能让玩家站桩 → 护盾 1.5s CD 与 9 点上限需要实测；
5. **greed + 高金币**：+15% 攻击上限已有，安全。

## 5. 冲突/互斥（需要在安装时提示）

- 专注核心**不与任何技能数量互斥**：它只在"装备技能 ≤2"时生效，4 技能流等于放弃该加成（设计意图，不是限制）；
- 冰系减速与"碎冰"增伤在 BOSS 身上需要按 BOSS 减速上限 30% 重算；
- 蓄能脉冲 + echo：只允许重放 1 次（防止 2 次大范围眩晕）。

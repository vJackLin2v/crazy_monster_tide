# 扩展验收标准（expansion_acceptance_criteria）

## 技能
- [ ] 第一批 4 个新技能上线且各有独特行为（环绕 / 陷阱 / 召唤 / 蓄力）；
- [ ] 每个新形态有实体上限（环绕 4、陷阱 4、召唤 1、蓄力 1）；
- [ ] 技能图鉴新增分类筛选；
- [ ] 不兼容的黑科技在安装时给出原因，不是静默无效。

## 黑科技
- [ ] 第一批 6 个模块均有 Hook、compat、BOSS 规则；
- [ ] 无递归：模块不触发自身；**split 衍生弹可以触发命中类模块，但必须遵守各模块的触发次数/频率上限**；module 来源伤害不再触发模块；
- [ ] 合成等级只放大允许成长的值，触发上限不变；
- [ ] 新增 6 条回归测试（每条模块至少 1 条边界用例）。

## 难度
- [ ] 五档参数集中在 data/Difficulties.ts，普通 = 当前基准；
- [ ] 难度选择页符合 360×640 规范，热区 ≥44；
- [ ] 解锁/锁定/奖励正确，老存档不丢进度；
- [ ] HUD / 暂停 / 结算显示难度；
- [ ] 无尽沿用本局难度，局内不可改。

## 道具
- [ ] 第一批 10 件均为机制型（有取舍或联动），不是纯数值；专注核心不改技能槽；
- [ ] 稀有度为**三档**（普通/稀有/传说），影响权重与价格，不直接等于强度；
- [ ] 传说道具每局上限 1；
- [ ] 商店/升级卡显示稀有度且不超宽。

## 工程
- [ ] 测试全绿，且**新增用例覆盖以下行为**（数量不是验收标准）：六模块正常触发/边界/来源过滤、五档倍率、BOSS 召唤状态机、老存档迁移、道具稀有度与每局传说上限、新技能实体上限与兼容性；
- [ ] tsc 双配置 exit 0；
- [ ] 微信构建通过，主包 < 3.6MB（留 0.4MB 余量）；
- [ ] 存档迁移有测试；
- [ ] 文档由代码生成（SKILLS/MODULES/ITEMS/DIFFICULTIES）。

## 旧系统回归基线（v5 新增，开发前必须建）

新增系统最容易伤到的不是新内容，而是旧内容。以下项必须在开发前记录基线、开发后逐项对比：

| 项 | 基线记录方式 | 判定 |
|---|---|---|
| 普通难度下原有 16 技能 DPS | 固定种子 + 固定构筑，记录每技能 10 秒输出 | 偏差 < 2% |
| 原有 18 黑科技触发逻辑 | 单测断言（现有 182 条中的相关用例保持全绿） | 不允许修改断言 |
| 原有 70 道具效果 | itemNumbers 全量快照对比 | 完全一致 |
| 普通商店价格 | 固定种子生成 20 波商店价格快照 | 完全一致 |
| 存档 | 旧档（无难度字段）读入后对比角色/成就/图鉴/金币 | 不丢失任何字段 |
| 普通难度刷怪 | 第 1/10/20 波生成数量快照 | 完全一致 |

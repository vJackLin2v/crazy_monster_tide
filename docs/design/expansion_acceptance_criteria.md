# 扩展验收标准（expansion_acceptance_criteria）

## 技能
- [ ] 第一批 4 个新技能上线且各有独特行为（环绕 / 陷阱 / 召唤 / 蓄力）；
- [ ] 每个新形态有实体上限（环绕 4、陷阱 4、召唤 1、蓄力 1）；
- [ ] 技能图鉴新增分类筛选；
- [ ] 不兼容的黑科技在安装时给出原因，不是静默无效。

## 黑科技
- [ ] 第一批 6 个模块均有 Hook、compat、BOSS 规则；
- [ ] 无递归：模块不触发自身，衍生弹不触发 onhit 新模块；
- [ ] 合成等级只放大允许成长的值，触发上限不变；
- [ ] 新增 6 条回归测试（每条模块至少 1 条边界用例）。

## 难度
- [ ] 五档参数集中在 data/Difficulties.ts，普通 = 当前基准；
- [ ] 难度选择页符合 360×640 规范，热区 ≥44；
- [ ] 解锁/锁定/奖励正确，老存档不丢进度；
- [ ] HUD / 暂停 / 结算显示难度；
- [ ] 无尽沿用本局难度，局内不可改。

## 道具
- [ ] 第一批 10 件均为机制型（有取舍或联动），不是纯数值；
- [ ] 稀有度影响权重与价格，不直接等于强度；
- [ ] 传说道具每局上限 1；
- [ ] 商店/升级卡显示稀有度且不超宽。

## 工程
- [ ] 测试全绿（当前基线 182，新增内容后应 ≥ 200）；
- [ ] tsc 双配置 exit 0；
- [ ] 微信构建通过，主包 < 3.6MB（留 0.4MB 余量）；
- [ ] 存档迁移有测试；
- [ ] 文档由代码生成（SKILLS/MODULES/ITEMS/DIFFICULTIES）。

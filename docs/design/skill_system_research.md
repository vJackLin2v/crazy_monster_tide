# 技能系统研究（skill_system_research）

## 1. 现有 16 技能的行为矩阵

| 形态 | 技能 | 打几只 | 打多远 | 持续 | 控制 | 特点 |
|---|---|---|---|---|---|---|
| 单发弹体 | 火球 / 冰晶矛 / 圣光弹 | 1（冰/圣可穿） | 远 | 瞬时 | 无 | 基础输出 |
| 高频弹体 | 奥术飞弹 / 圣光弹 | 1 | 远 | 瞬时 | 无 | 吃攻速收益高 |
| 追踪弹体 | 奥术 / 雷球 / 灵能箭 | 1 | 远 | 瞬时 | 冰/无 | 不吃准度 |
| 回旋弹体 | 回旋刃 | 2 次经过 | 中 | 往返 | 无 | 唯一"返程"机制 |
| 脉冲（自身为中心） | 震荡波 / 霜爆 / 荆棘环 / 寒冰环 | 全体近身 | 近 | 瞬时 | 霜爆/寒冰减速 | 需要贴脸 |
| 地面区域 DoT | 毒雾 / 陨石 / 乱杀 / 扎心 | 区域内全体 | 近-中 | 2.4~4.2s | 毒雾减速?无 | 靠停留时间收益 |
| 连锁 | 连锁闪电 | 链式 2~N | 中 | 瞬时 | 无 | 唯一链式 |

## 2. 重复度判定

- **霜爆 vs 寒冰环 vs 震荡波 vs 荆棘环**：都是"以自身为中心的瞬时圆"，差异只有伤害/冷却/减速；
- **毒雾 vs 扎心 vs 乱杀 vs 陨石**：都是"地面圆形 DoT"，差异只有半径、跳速、持续时间；
- 也就是说 16 个技能里，**真正不同的战斗行为只有 5 类**：直射弹、追踪弹、回旋弹、自身脉冲、地面 DoT，加 1 个链式。

## 3. 缺失的攻击形态

| 缺失形态 | 为什么重要 |
|---|---|
| 环绕物（持续跟随玩家旋转） | 提供"近身持续输出"但不需要贴脸施法，与脉冲是不同操作感 |
| 地面陷阱（敌人踩到才爆） | 让玩家可以"预布置"，与走位绑定 |
| 召唤物（自动射击的哨兵） | 提供"多一个输出源"，改变玩家站位策略 |
| 蓄力/周期大范围（每 N 秒一次） | 提供节奏感，与高频技能形成互补 |
| 防御型反击（受击触发） | 目前只有 thornmail 一个被动，缺少技能级反击 |
| 延迟分段爆炸（先落点再连锁） | 现有陨石只有一次落点爆发 |

## 4. 强弱与流派现状

- 强：陨石（高爆发 + 区域）、连锁闪电（多目标）、回旋刃（双段命中）；
- 弱：扎心（5 伤害 / 2s，被毒雾全面压制）、荆棘环（10 伤害 / 2.6s，被震荡波 14 / 2.4s 压制）；
- 现有可形成流派：多重投射（multi+fan+split）、元素 DoT（burn+frost）、雷链（chain+thunder）—— **都建立在"弹体/命中"上**，没有"召唤/陷阱/环绕"流派。

## 5. 新技能设计方向（先研究，不直接定稿）

1. 环绕型：随身旋转的刀刃/火球，持续伤害贴身的敌人；
2. 陷阱型：放置地雷/尖刺，敌人踩中触发；
3. 召唤型：召唤一个哨兵自动射击；
4. 蓄力型：每 4 秒蓄力一次，放一发大范围；
5. 反击型：受击时反弹一圈伤害；
6. 分段型：落点爆炸后延迟二次爆炸。

## 6. 兼容方案（关键约束）

- 新技能必须声明 type 与 tags，Battle.fireSkill 按 type 分派；
- 若新增 type（orbit / trap / summon / charge / counter / staged），必须同时在 Battle 增加对应 update 分支与上限（实体数、同时存在数）；
- 黑科技兼容：calc 类（multi/fan/rapid/giant/snipe/overload）对"无弹体"技能无效 → 安装时必须给出明确原因（现有 canInstall 已检查 hook 兼容，需要为 orbit/trap 补规则）；
- **召唤物与陷阱必须有全局上限**（例如召唤 1 个、陷阱 4 个），否则无尽模式会无限增长。

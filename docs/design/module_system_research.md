## 2. 结构性问题

1. **7 个 calc 模块里 4 个（multi/fan/orbit/snipe）本质都是"增加弹体/弹速"**，对无弹体技能全部无效；
2. **没有 oncrit（暴击时）**：暴击流只有属性道具支撑，没有模块；
3. **没有 onkill AoE**：收割流只有 harvest（回血），缺少"击杀连锁"；
4. **没有"受击/护盾"类**：防御向只有 thornmail 一个；
5. **没有"返程"类**：回旋刃的返程没有专属模块；
6. **没有"蓄势"类**：蓄力型技能（新技能 charge）缺少配套。

## 3. 容易数值膨胀的模块

- multi + fan + split + bounce：单次施法弹体可达 35 枚（已核算，有上限）；
- echo + rapid：重放不消耗冷却，理论上 2.8× 爆发；
- overload + burn：灼烧跳数吃到 overload 的增伤，需要确认是否重复计算。

## 4. 可扩展方向（不重复现有）

| 方向 | 为什么是新的 |
|---|---|
| 击杀连锁爆炸 | 现在击杀只回血，没有范围反馈 |
| 命中生成护盾 | 现在防御只有反伤 |
| 处决（低血增伤） | 现在没有"斩杀"机制 |
| 返程增伤 | 回旋刃专属，鼓励"接刀"走位 |
| 命中留下区域 | 现在区域来自技能本体，不来自命中 |
| 蓄势（第 N 次施法强化） | 与 echo 相反：echo 是重放，蓄势是"攒一次大的" |

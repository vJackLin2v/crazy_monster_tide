# 难度系统设计（difficulty_system_design）

## 1. 设计原则

- 五档都必须有**独特的挑战特色**，不是"血量 100%→300%"；
- **普通 = 当前版本基准**，玩家感知到的是"和以前一样"；
- 休闲不能无挑战（否则玩家不会往上走）；地狱必须可通关（否则没有意义）；
- 难度只能**开局选择**，局内不可改；无尽沿用本局难度；
- 解锁逐级推进，但**老玩家不丢进度**（默认解锁普通，历史通关记录用于补解锁）。

## 2. 配置结构（建议 data/Difficulties.ts）

| 字段 | 含义 |
|---|---|
| enemyHpMul / enemyDmgMul | 怪物血量/伤害倍率 |
| spawnMul | 刷怪间隔倍率（>1 更慢） |
| eliteMul / bossHpMul / bossDmgMul | 精英概率、BOSS 数值 |
| goldMul / expMul | 金币/经验倍率 |
| shopPriceMul / rerollMul | 商店价格、刷新费用倍率 |
| healMul | 回血效率倍率 |
| startHpMul | 玩家初始生命倍率 |
| restrictions[] | 结构化限制（用于 UI 展示 + 运行时校验） |
| unlock | 解锁条件（上一难度通关） |
| rewards[] | 徽章/成就/图鉴标记（**不给局内数值**） |

## 4. 每档的"特色规则"（不只是倍率）

### 休闲（新手）
- 第 1~3 波不生成精英；
- 玩家血量低于 30% 时回血效率额外 ×1.2（保底体验）；
- 商店必定出现至少 1 件攻击向道具。

### 普通（基准）
- 与当前版本完全一致，用于对照。

### 困难（构筑入门）
- 第 12 波起精英有 25% 概率带"护盾词缀"（额外 20% 生命）；
- 商店**不出售**治疗商品；
- 每波刷新次数上限 3（普通无限）。

### 噩梦（构筑考验）
- 第 8 波起精英必带 1 个词缀（护盾/加速/分裂）；
- BOSS 每损失 25% 生命召唤 3 只小怪（上限 6 只）；
- 金币获取 -15%，且商店**锁定需要花费 2 金币**；
- 玩家回血预算从 8HP/s 降到 6HP/s。

### 地狱（极限）
- 第 5 波起精英每 3 波必出，且必带 2 个词缀；
- BOSS 有"狂怒"：血量 <30% 时伤害 +25%、移速 +15%；
- 商店价格每波 +2%（普通不加）；
- 玩家**初始生命 85%**，且回血预算 5HP/s；
- 通关奖励：地狱徽章 + 成就 + 图鉴金色边框。

## 5. 解锁与奖励

| 难度 | 解锁条件 | 奖励 |
|---|---|---|
| 休闲 | 默认 | — |
| 普通 | 默认（老玩家直接开放） | — |
| 困难 | 普通通关 1 次 | 困难徽章 |
| 噩梦 | 困难通关 1 次 | 噩梦徽章 + 成就 |
| 地狱 | 噩梦通关 1 次 | 地狱徽章 + 金色图鉴框 + 专属成就 |

- 老存档迁移：`difficulties = ["casual","normal"]`，若 `wins >= 1` 追加 `hard`；
- 所有奖励**不提供局内数值**，避免"刷低难度换强度"。

## 6. 无尽模式

- 进入无尽**保留本局难度**，不可切换；
- 无尽沿用该难度的成长倍率与限制；
- 无尽第 30/40/50 波各给 1 个"难度徽章进度"（不计入 20 波通关）；
- 结算页记录"难度 + 最高波次"。

## 7. 存档与兼容

- Progress 新增 `difficulty`（当前局）与 `difficulties`（已解锁数组）；
- 缺字段时：`difficulty = "normal"`、`difficulties = ["casual","normal"]`；
- **不重置任何既有字段**；迁移只做加法。

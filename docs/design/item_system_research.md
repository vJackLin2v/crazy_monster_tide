| 类别 | 数量 | 代表 | 说明 |

## 2. 结论

1. **属性覆盖率很高**：24 个属性都有 2 档，几乎没有"缺属性"；
2. **机制稀释严重**：50 件 tier1 里 48 件只是倍率/加值，玩家选择时只比大小；
3. **没有取舍型道具**（拿生命换攻击、拿技能槽换强度）；
4. **没有经济联动**（金币→攻击、刷新费→收益）；
5. **没有流派向道具**（"冰系强化"只有 1 件标签加成，撑不起流派）。

## 3. 道具价值盘点（抽样）

| 类别 | 强 | 弱 | 备注 |
|---|---|---|---|
| 攻击向 | power_l、critdmg_l | projspd_s | 弹速对近身技能无用 |
| 生存向 | armor_l、invuln | regen_s（0.4/s≈无感） | 回复数值太低 |
| 经济向 | gold_l | exp_s | 经验只在低波有用 |
| 元素向 | fire/bolt | nature | 自然系技能只有 2 个 |

## 4. 需要补的流派（每派至少 3 件道具 + 2 技能 + 2 黑科技）

暴击爆发 / 多重投射 / 元素 DoT / 范围清场 / 冰冻控制 / 雷电连锁 / 近身反伤 / 吸血续航 / 高移速 / 经济成长 / 经验成长 / 高风险高收益。

## 5. 新道具的定位原则

- 每件必须**改变一个决策**，而不是只改数字；
- 有代价的收益必须写明负面；
- 不新增"第 25 个属性"这种纯数值道具；
- 尽量复用现有 apply(stats) 接口，必要时新增 flags（如 lowHpBonus、goldToPower）。

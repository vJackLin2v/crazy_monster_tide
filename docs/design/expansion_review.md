# 设计评审记录（expansion_review）

> 汇总三轮人工审核的结论与修订结果。**唯一规则来源见 FINAL_DESIGN_DECISIONS.md**；
> 本文只记录"改过什么、为什么改"，旧方案一律标记为已作废，不作为开发依据。

## 一、第一轮评审（v2 前）

| 编号 | 问题 | 处理 |
|---|---|---|
| R1 | 新技能与模块 orbit 命名冲突 | 新技能改名 ring_blade |
| R2 | 蓄能脉冲 + echo 可能连放两次大眩晕 | charge 类 echo 重放上限 1 次，眩晕不叠加 |
| R3 | 蓄势是否统计 echo 重放未定义 | 不统计（以 castId 计数） |
| R4 | killblast 与 execute 可能重复结算 | 爆炸伤害来源固定 module，不触发 execute |
| R5 | 地雷与扎心定位接近 | 地雷=陷阱（踩到才爆），扎心=区域 DoT |
| R6 | 集中资源类道具原方案影响技能槽 | **已作废**，改为「专注核心」：技能 ≤2 时 +25% 伤害 / -10% 冷却，不改技能槽 |
| R7 | 地狱商店涨价幅度 | 定稿 **+2%/波，增量封顶 +35%**，最终最高 1.8225 倍基础价 |
| R8 | 噩梦 BOSS 召唤与同屏上限冲突 | 召唤受同屏上限约束，且 ≤6 只 |
| R9 | 道具稀有度分层 | **采用三档**：普通 / 稀有 / 传说 |
| R10 | 图鉴金框需要数据结构 | 条目增加 goldFrame 标记，不改 seen |

## 二、第二轮评审（v3 前）

- 明确 DamageSource 判定不等于"额外攻击一律无效"，改由 DamageContext 统一判断；
- M3/M4/M5/M6 的叠加公式由"基础 + 每份"改写为三档具体数值；
- 噩梦 BOSS 召唤补充状态机；地狱初始生命改 90%，85% 降为可选挑战；
- 稀有度改三档；专注核心不改变技能槽。

## 四、审核后追加的规则（本轮）

- 蓄能脉冲：目标死亡**立即重新索敌**、无目标**暂停蓄力**、空放返还**剩余冷却 50%**、echo 重放**不重新蓄力**；
- 传说道具每局最多 1 件，**商店与升级池共享计数**；
- 模拟计划增加三类观测：模块每秒触发次数/来源分布/递归深度、各难度购买次数与死亡波次、12 套构筑的 DPS 与存活率。

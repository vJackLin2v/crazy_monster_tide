# 新黑科技设计 v2（module_expansion_design）

> 依据人工确认意见：**先定统一事件规则**，再逐条审核 6 张模块卡。

## 1. 伤害来源标记（开发必须实现）

每次伤害/效果触发都要带来源，统一由 `DamageSource` 判断能否再触发其他模块：

| 来源 | 含义 |
|---|---|
| normal | 技能本体 |
| split | 分裂衍生弹 |
| echo | 复读重放 |
| chain | 连锁跳 |
| module | 黑科技产生的额外伤害 |
| summon | 召唤物 |

## 2. 事件规则表（已确认，开发时照此实现）

| 事件 | 是否允许 |
|---|---|
| 普通技能命中触发黑科技 | 允许 |
| 黑科技产生额外伤害 | 允许 |
| 黑科技额外伤害再次触发同类黑科技 | **禁止** |
| 重放攻击造成普通伤害 | 允许 |
| 重放攻击增加蓄力层数 | **禁止** |
| 重放攻击增加连击计数 | 默认**禁止** |
| 分裂弹触发普通命中效果 | 允许，但必须有次数上限 |
| 分裂弹再次分裂 | **禁止递归** |
| 黑科技生成的召唤物触发黑科技 | 默认**禁止** |
| 额外伤害再次生成额外伤害 | **禁止递归** |

注意：不是"额外攻击一律不触发"，而是**按来源判定**——`module` 来源不能触发 `module` 类效果，但可以正常造成伤害与叠加状态。

## 3. 六张模块卡（请逐条审核）

### M1 killblast · 溢出爆裂

| 字段 | 值 |
|---|---|
| hook | kill |
| 来源 | module |
| 触发条件 | 敌人死亡（仅 normal/split 命中的击杀；module 伤害导致的击杀**不触发**） |
| 效果 | 对 40px 内敌人造成 8 伤害 |
| 叠加 | 伤害 +6/份，半径 +6/份（半径上限 70） |
| 份数上限 | 3 |
| 递归限制 | 爆炸**不触发自身、不触发 execute、不触发其他 onhit 模块** |
| BOSS 规则 | 对 BOSS 无效 |
| 频率上限 | 每次击杀 1 次 |
| 性能上限 | 单次判定 ≤60 只 |

### M2 shieldonhit · 残影护盾

| 字段 | 值 |
|---|---|
| hook | onhit |
| 来源 | 仅 normal / chain |
| 触发条件 | 命中敌人 |
| 效果 | 获得 3 点护盾，4s 后消失 |
| 叠加 | 护盾 +2/份（**上限 9**） |
| 份数上限 | 3 |
| 递归限制 | 护盾不触发任何伤害类模块；same 效果 1.5s 内只结算 1 次 |
| BOSS 规则 | 无特殊 |
| 性能 | 无实体 |

### M3 execute · 处决

| 字段 | 值 |
|---|---|
| hook | onhit |
| 来源 | normal / split / chain / echo（**module 伤害不享受**） |
| 触发条件 | 目标生命 <30% |
| 效果 | 本次伤害 +40% |
| 叠加 | +18%/份，**上限 +90%** |
| 份数上限 | 3 |
| 递归限制 | 只改本次伤害，不产生新伤害事件 |
| BOSS 规则 | 增伤减半（+20%） |
| 性能 | 无额外判定 |

### M4 returnstrike · 返程斩

| 字段 | 值 |
|---|---|
| hook | onreturn（新增） |
| 来源 | normal（回旋弹体返程阶段） |
| 触发条件 | 仅 `return` 标签技能 |
| 效果 | 返程命中额外造成 70% 伤害 |
| 叠加 | +25%/份，**上限 120%** |
| 份数上限 | 3 |
| 递归限制 | 额外伤害来源标记为 module，不触发 onhit 类模块 |
| BOSS 规则 | 正常 |
| 性能 | 每枚弹体每次返程 1 次 |

### M5 lingering · 焚烧地带

| 字段 | 值 |
|---|---|
| hook | onhit |
| 来源 | normal / split（split 触发概率减半） |
| 触发条件 | 命中时 35% 概率 |
| 效果 | 地面留下 1.5s 灼烧区，每 0.5s 造成 30% 伤害 |
| 叠加 | 概率 +10%/份（**上限 65%**），伤害比例不变 |
| 份数上限 | 3 |
| 递归限制 | 灼烧区伤害来源 = module，**不再触发 onhit** |
| BOSS 规则 | 正常 |
| 性能 | **同屏最多 4 个区域**，超出移除最早的 |

### M6 overcharge · 蓄势

| 字段 | 值 |
|---|---|
| hook | calc |
| 来源 | — |
| 触发条件 | 每第 4 次施法（每份 -1，最少第 2 次） |
| 效果 | 本次施法伤害 +80% |
| 叠加 | +30%/份，**上限 +140%** |
| 份数上限 | 3 |
| 递归限制 | **echo 重放不计入施法计数**（否则 2 秒触发一次） |
| BOSS 规则 | 正常 |
| 性能 | 仅整数计数 |

## 5. 需要补的测试（开发时）

1. module 来源不触发 module 类效果（killblast 不连锁）；
2. echo 重放不增加 overcharge 计数；
3. lingering 区域上限 4；
4. shieldonhit 1.5s CD 与 9 点上限；
5. execute 对 BOSS 减半；
6. returnstrike 仅 return 标签生效。

# 新黑科技设计 v3（module_expansion_design）

> 依据 v2 审核意见修订：明确最终公式、触发边界、CD、递归规则。**仍未开发。**

## 1. 六个模块最终数值表（开发以此为准）

### M1 killblast · 溢出爆裂（通过）

| 项 | 最终定义 |
|---|---|
| hook / 来源 | kill；伤害来源固定为 module |
| 触发 | 敌人死亡，且致死伤害来源 ∈ {normal, split} |
| 效果 | 对 40px 内敌人造成 8 伤害 |
| 份数 | 1 / 2 / 3 份 → 伤害 8 / 14 / 20；半径 40 / 46 / 52（**每份 +6px，随份数成长**；半径不受玩家范围属性影响） |
| 目标选择 | 只筛半径内敌人；**超过 60 只时取距爆心最近的 60 只**（不随机，保证可复现） |
| 递归 | 爆炸伤害来源 = module → **不触发自身、不触发 execute、不触发任何 onhit 模块**；爆炸的击杀也不触发爆炸 |
| BOSS | 对 BOSS 无效；**可以击杀精英**，只是不再连锁 |
| 性能 | 单次 ≤60 只判定 |

### M2 shieldonhit · 残影护盾（修订：全局 CD + 叠加刷新）

| 项 | 最终定义 |
|---|---|
| hook / 来源 | onhit；可触发来源 ∈ {normal, chain, split} |
| 触发 CD | **全局共享 1.5 秒**（不是按敌人分别计时）；chain 的多次跳跃也共享同一个 CD |
| 效果 | 获得 3 点护盾；份数 1/2/3 → **3 / 5 / 7 点**（每份 +2，池上限 9） |
| 叠加 | **单层护盾池**：新护盾直接加到当前值，**上限 9**；不产生多计时器 |
| 刷新 | 每次获得护盾时，4 秒计时**重新开始** |
| 过期 | 4 秒到 → 剩余护盾全部清零（不是只清掉最近一次） |
| 递归 | 护盾不产生伤害事件，不触发任何模块 |
| BOSS | 无特殊 |

### M3 execute · 处决（修订：三档公式 + 结算前判定）

| 项 | 最终定义 |
|---|---|
| hook / 来源 | onhit；享受加成来源 ∈ {normal, split, chain, echo}；**module 伤害不享受** |
| 判定 | **本次伤害结算前**目标生命比例 < 30%（结算后跌破不算） |
| 份数 | 1 / 2 / 3 份 → +40% / +58% / +76%（公式：40 + 18×(份数-1)） |
| BOSS | 增伤减半：+20% / +29% / +38%（四舍五入到整数百分比） |
| 递归 | 只改本次伤害数值，不产生新伤害事件 |

### M4 returnstrike · 返程斩（修订：三档公式 + 单次返程）

| 项 | 最终定义 |
|---|---|
| hook / 来源 | onreturn；额外伤害来源 = module |
| 生效范围 | **仅 return 标签技能**（当前只有回旋刃） |
| 触发 | 弹体进入返程阶段并命中敌人时 |
| 份数 | 1 / 2 / 3 份 → 额外 70% / 95% / 120%（公式：70 + 25×(份数-1)） |
| 限制 | 同一弹体的同一次返程只触发 1 次（用 projectileId + 返程序号判定） |
| 保留 | **返程原本的普通伤害照常结算**，返程斩是额外附加，不替换 |
| BOSS | 正常生效 |

### M5 lingering · 焚烧地带（微调：概率 35/45/55）

| 项 | 最终定义 |
|---|---|
| hook / 来源 | onhit；区域伤害来源 = module |
| allowedSources | normal / split（split 概率减半）；echo / chain / module / summon 不允许 |
| 触发概率 | 份数 1/2/3 → normal 35% / 45% / 55%；split 来源减半（17.5% / 22.5% / 27.5%） |
| 区域 | 持续 1.5 秒，每 0.5 秒 1 跳，**共 3 跳**；每跳 = 触发时技能伤害的 30% |
| 伤害快照 | **生成区域时锁定伤害值**，之后玩家属性变化不影响该区域 |
| 上限 | 全场最多 4 个区域，超出时删除最早生成的 |

| 同帧生成 | 按创建序号排序，超出 4 个时删除序号最小（最早）的 |
| 删除行为 | 被删除区域**立即停止后续跳伤**（不结算剩余跳数） |
| 伤害快照 | 区域伤害在生成瞬间锁定，之后玩家属性变化不影响该区域 |
| 伤害来源 | 固定 module（不再触发任何 onhit 模块） |
| 递归 | 区域伤害来源 = module，不再触发 onhit 模块 |
| BOSS | 正常 |

### M6 overcharge · 蓄势（修订：castId 计数 + 三档公式）

| 项 | 最终定义 |
|---|---|
| hook | calc（施放前判定） |
| 触发 | 份数 1 / 2 / 3 → 每 3 / 2 / 2 次施法一次 |
| 伤害 | 该次施法 +80% / +110% / +140% |
| 计数依据 | **以 castId 为唯一计数单位**：一次施法无论产生多少弹体/连锁，只计 1 次 |

| 计数时机 | 每次**玩家主动施放**生成新 castId → 该技能计数 +1 → 若达到周期则本次施法享受加成，随后计数归零 |
| 周期表 | 1 份：第 3 次施法生效；2 份：第 2 次；3 份：第 2 次（生效后重新从 0 计数） |
| echo | 不计数、不重置周期 |
| 不计数 | echo 重放、召唤物攻击、黑科技额外伤害、分裂衍生弹 |
| 计数作用域 | 按技能独立计数（每个技能自己的 castId 序列） |
| BOSS | 正常 |

## 2. 审核结论表（v3 状态）

| 模块 | 结论 | 本轮补充 |
|---|---|---|
| M1 溢出爆裂 | 通过 | 60 只取最近、爆炸击杀不触发爆炸、可击杀精英 |
| M2 残影护盾 | 通过 | 全局 1.5s CD、单层护盾池上限 9、获得即刷新 4s、过期全清 |
| M3 处决 | 通过 | 40/58/76 与 BOSS 20/29/38、结算前判定 |
| M4 返程斩 | 通过 | 70/95/120、单次返程一次、保留原返程伤害 |
| M5 焚烧地带 | 通过 | 35/45/55（split 减半）、3 跳、伤害快照、最多 4 区 |
| M6 蓄势 | 通过 | 3/2/2 次与 80/110/140、castId 计数 |

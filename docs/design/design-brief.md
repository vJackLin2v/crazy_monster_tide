# 《疯狂鸽王》设计说明（供外部评审）

> 自动生成：直接读取项目源码数据表，保证与实际运行一致。
> 游戏：竖屏像素风自动射击 roguelike；玩家只控制走位，4 个主动技能自动开火。

## 0. 一局的流程

- 20 波，每波有倒计时，撑到时间结束即过波；每 3 波出精英，第 10 / 20 波是 BOSS。
- 击杀掉经验球（需走到范围拾取）+ 金币；升级弹 3 选 1（技能 / 黑科技 / 道具 / 属性）。
- 波间商店：4 个货位，可买 / 锁定 / 刷新；模块买入后进背包，进下一波前统一安装。
- 4 个技能槽，每技能 3 个黑科技槽；3 个同名黑科技可合成 Ⅱ（效果×2、占 1 槽）。

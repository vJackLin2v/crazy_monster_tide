# 难度选择 UI 规范（difficulty_ui_spec）

> 画布 360×640，安全区 S/B 由 Safe.ts 提供；复用 UIKit 组件，不新造视觉。

## 1. 流程选择

两个候选：
- A：主菜单 → 难度 → 选角 → 开始；
- B：主菜单 → 选角 → 难度 → 开始。

**选定 A**：难度影响商店/经济/生存，玩家应在**选角前**就知道自己将面对什么，再决定用什么角色应对。B 会让玩家先挑角色后被难度"打脸"，重选成本高。

## 2. 页面布局（设计坐标，y 从屏幕顶算）

| 元素 | 位置 / 尺寸 | 说明 |
|---|---|---|
| 标题「选择难度」 | y=S+52，32px 粗体 | 与选角页同款 |
| 副标题「选择适合你的挑战」 | y=S+82，11px dim | — |
| 难度行 ×5 | 每条 336×48，起始 y=S+118，间距 56 | 左侧名称 16px，右侧星级 ★☆☆☆☆ |
| 选中态 | 描边 3px 强调色 + 左侧 6px 色条 | 与升级卡同一套选中语言 |
| 锁定态 | 名称变 dim + 右侧锁图标 + 星级灰 | 点击弹「解锁条件」提示 |
| 详情面板 | y=S+400，336×150，panel | 显示 3 条主要限制 + 3 条次要规则 + 奖励一行 |
| 主按钮「确认并选择角色」 | y=640-B-64，336×48 | 主色 |
| 次按钮「返回」 | y=640-B-14，336×44 | 描边 |

## 3. 详情面板内容（每档最多 6 行 + 1 行奖励）

- 主要挑战（3 条，带图标）：怪物更硬 / 攻击更危险 / 物资短缺；
- 次要规则（3 条，10px dim）：刷新更贵 / 回血变慢 / 精英更多；
- 奖励（1 行，accent 色）：通关解锁「噩梦徽章」。

**文案要求**：说出后果，而不是只报倍率。例：
- ❌「怪物伤害 +50%」
- ✅「敌人更危险：承受伤害提高 50%」

## 4. 交互

1. 点难度行 → 立即切换选中态并刷新详情（无二次确认）；
2. 点锁定行 → 弹 toast：「通关『困难』后解锁」，不改变当前选择；
3. 「确认并选择角色」→ 保存 `save.difficulty` 后进选角页；
4. 「返回」→ 回主菜单，**保留已选难度**；
5. 选角页顶部显示「难度：困难」小徽章，可点击返回难度页修改。

## 5. 其他页面联动

| 页面 | 展示 |
|---|---|
| 选角页 | 标题下「难度：困难」11px 徽章 |
| 战斗 HUD | 右上角波次行末尾追加「· 困难」（10px，dim）；不新增独立元素 |
| 暂停抽屉 | 标题下「第 9 波 · 已暂停 · 困难」 |
| 结算页 | 卡片区加一行「通关难度：噩梦」 |
| 成就页 | 难度徽章作为一组（5 个格子） |
| 图鉴/记录 | 图鉴条目显示「首次通关难度」 |

## 6. 验收点

- 360×640 无文字裁切，最小字号 10px；
- 热区 ≥44×44（难度行 48 高已满足）；
- 5 行 + 详情 + 两按钮在安全区内放得下（需实测：S=28/B=10 时总高 640）；
- 锁定难度不可确认；
- 返回后保留选择；
- 与现有 UIKit 风格一致（不引入新配色/新圆角）。

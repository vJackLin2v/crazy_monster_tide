# 难度选择 UI 规范（difficulty_ui_spec）

> 画布 360×640，安全区 S/B 由 Safe.ts 提供；复用 UIKit 组件，不新造视觉。

## 1. 流程选择

两个候选：
- A：主菜单 → 难度 → 选角 → 开始；
- B：主菜单 → 选角 → 难度 → 开始。

**选定 A**：难度影响商店/经济/生存，玩家应在**选角前**就知道自己将面对什么，再决定用什么角色应对。B 会让玩家先挑角色后被难度"打脸"，重选成本高。

## 2. 页面布局（v4 修正，已验证不溢出）

设计坐标，y 从屏幕顶算；S=28，B=10 时全部落在安全区内（最低元素结束于 620）。

| 元素 | y（顶部） | 高度 | 说明 |
|---|---:|---:|---|
| 标题「选择难度」 | S+52 = 80 | 32 | 26px 粗体 |
| 副标题 | S+82 = 110 | 14 | 11px dim |
| 难度行 1 | S+118 = 146 | 40 | 每行 336×40，pitch 44 |
| 难度行 2 | 190 | 40 | |
| 难度行 3 | 234 | 40 | |
| 难度行 4 | 278 | 40 | |
| 难度行 5 | 322 | 40 | 最后一行结束 362 |
| 详情面板 | 370 | 136 | 结束 506，与主按钮留 14px |
| 主按钮「确认并选择角色」 | 520 | 48 | 结束 568 |
| 返回按钮 | 576 | 44 | 结束 **620**，落在 640-10 之内 |

校验：
- 5 行结束 362 < 详情 370 ✔；
- 详情结束 506 < 主按钮 520 ✔（无重叠）；
- 返回结束 620 <= 640-10 ✔。

行内布局：名称 16px 左对齐（x=24），星级 11px 右对齐（x=336），选中时左侧 6px 色条 + 3px 描边。

## 3. 详情面板内容（每档最多 6 行 + 1 行奖励）

- 主要挑战（3 条，带图标）：怪物更硬 / 攻击更危险 / 物资短缺；
- 次要规则（3 条，10px dim）：刷新更贵 / 回血变慢 / 精英更多；
- 奖励（1 行，accent 色）：通关解锁「噩梦徽章」。

**文案要求**：说出后果，而不是只报倍率。例：
- ❌「怪物伤害 +50%」
- ✅「敌人更危险：承受伤害提高 50%」

## 4. 交互

1. 点难度行 → 立即切换选中态并刷新详情（无二次确认）；
2. 点锁定行 → 弹 toast：「通关『困难』后解锁」，不改变当前选择；
3. 「确认并选择角色」→ 保存 `Progress.selectedDifficulty` 后进选角页；
4. 「返回」→ 回主菜单，**保留已选难度**；
5. 选角页顶部显示「难度：困难」小徽章，可点击返回难度页修改。

## 5. 其他页面联动

| 页面 | 展示 |
|---|---|
| 选角页 | 标题下「难度：困难」11px 徽章 |
| 战斗 HUD | 右上角波次行末尾追加「· 困难」（10px，dim）；不新增独立元素 |
| 暂停抽屉 | 标题下「第 9 波 · 已暂停 · 困难」 |
| 结算页 | 卡片区加一行「通关难度：噩梦」 |
| 成就页 | 难度徽章作为一组（5 个格子） |
| 图鉴/记录 | 图鉴条目显示「首次通关难度」 |

## 6. 验收点

- 360×640 无文字裁切，最小字号 10px；
- 热区 ≥44×44（难度行 48 高已满足）；
- 5 行 + 详情 + 两按钮在安全区内放得下（需实测：S=28/B=10 时总高 640）；
- 锁定难度不可确认；
- 返回后保留选择；
- 与现有 UIKit 风格一致（不引入新配色/新圆角）。

## 7. 触摸热区（v5，与视觉尺寸分开）

| 项 | 值 |
|---|---|
| 视觉卡片高度 | 40px（行高 40，pitch 44） |
| 实际点击热区 | 44x44（横向 336 宽，上下各外扩 2px 与相邻行衔接） |
| 行间空隙 | 44 - 40 = 4px，被热区覆盖，不能出现点不到的空隙 |
| 与详情面板间距 | 最后一行热区底 366，详情面板顶 370，留 4px |

按钮同样按 44 校验：主按钮 48 高、返回 44 高，均达标。

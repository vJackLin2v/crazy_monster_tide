# 新技能设计 v2（skill_expansion_design）

> 依据人工确认意见修订：四个方向通过，但**必须各有不同定位**，不能换皮。
> 定位：环绕=近身防御、陷阱=区域控制、召唤=自动追击、蓄力=单体爆发。

## 1. 环刃（ring_blade）· 近身防御

| 字段 | 值 |
|---|---|
| type | orbit |
| tags | physical, orbit, melee, defense |
| 定位 | **持续贴身防守**：怪贴上来就掉血，玩家可以放心站着输出 |
| 伤害 / 存在 | 每片刀刃每秒 6 伤害（每 0.25s 判定一次，单次 1.5） |
| 范围 | 以玩家为圆心、半径 40px 的环带（刃宽 10px） |
| 片数 | 初始 2 片，每级 +1，**上限 4 片** |
| 转速 | 1.4 圈/秒（受 rapid 加成，上限 2.2 圈/秒） |
| 目标 | 环带内全部敌人，**不区分目标数量** |
| 兼容 | giant（半径 +30%）、rapid（转速）有效；multi/fan/split/pierce/bounce/chain **无效**（无弹体），安装时给出原因 |
| 弱点 | 只有贴脸才打得到；对远程/风筝型敌人零输出；**不能打 BOSS 外围** |
| 性能 | 最多 4 片 × 每 0.25s 一次圆形判定 |

**与现有技能的区别**：脉冲（震荡波/霜爆/荆棘环/寒冰环）是"瞬发一圈然后等冷却"，环刃是**常驻**且随玩家移动，属于持续防御而非爆发。

## 2. 地雷阵（mine_field）· 区域控制

| 字段 | 值 |
|---|---|
| type | trap |
| tags | physical, trap, area, control |
| 定位 | **预布置 + 引怪**：玩家主动把怪群带到雷区 |
| 伤害 | 单雷 22，爆炸半径 44px |
| 布置 | 施放时在脚下放 1 枚，0.6s 后进入待触发 |
| 上限 | **同屏最多 4 枚**；超过时最早的一枚立即引爆（不会消失，避免浪费） |
| 触发 | 敌人进入 16px 判定圈即爆 |
| 兼容 | giant（半径）、burn（爆炸挂灼烧）有效；pierce/bounce/chain 无效 |
| 弱点 | **对移动快的怪命中率低**（狼/眼球蝠）；需要玩家预判走位 |
| 性能 | 最多 4 枚静态实体，每帧 4×N 距离检测 |

**与扎心的区别**：扎心是"站上去持续掉血"的地面 DoT；地雷是"踩到才爆"的离散触发，且**需要玩家布置**。

## 3. 哨戒哨兵（sentry）· 自动追击

| 字段 | 值 |
|---|---|
| type | summon |
| tags | arcane, summon, projectile, auto |
| 定位 | **多一个输出源**：玩家可以专心走位，让哨兵持续打 |
| 伤害 | 每发 6，射速 0.9s/发 |
| 存在 | 8s；重复施放会**移动**哨兵到当前位置并刷新时长（不是新增） |
| 上限 | **同时 1 个**（硬上限，防止无限堆） |
| 行为 | 自动索敌最近的敌人（射程 160px），弹体可被 multi/fan/snipe/rapid 影响 |
| 兼容 | multi/fan/snipe/rapid；orbit/trap 无效 |
| 弱点 | 哨兵**不会移动**，怪群会绕开；输出依赖玩家把它放对位置 |
| 性能 | 1 个哨兵 × 1.1 发/秒 |

## 4. 蓄能脉冲（charge_pulse）· 单体爆发 / 精英攻坚

| 字段 | 值 |
|---|---|
| type | charge |
| tags | lightning, charge, burst, boss |
| 定位 | **点名精英/BOSS 的高爆发**，不是清场技能 |
| 蓄力 | 3.0s 蓄力（地面出现收缩光圈 + 角色描边发亮，**必须可读**） |
| 释放 | 对**当前锁定目标**造成 26 基础伤害 ×蓄力层数加成，并对 90px 内其他敌人造成 40% 伤害 |
| 冷却 | 4.0s（蓄力 + 1s 收尾） |
| 成长 | 每级 +6 单体伤害、+8px 溅射半径 |
| 兼容 | overload（蓄满增伤）、giant（半径）；**echo 重放上限 1 次**，且眩晕不叠加 |
| 目标死亡 | **立即重新索敌**并用剩余蓄力时间继续（不重置蓄力进度） |
| 无目标 | **暂停蓄力**（进度保留），出现目标后继续；场上无敌人时不会空放 |
| 空放返还 | 蓄力完成但目标已消失 → 返还**当前剩余冷却的 50%** |
| echo 重放 | **不重新进入蓄力**（直接以已蓄满的数值结算一次） |
| 性能 | 单次大范围判定 |

**与"长冷却技能"的区别**：现有陨石是"CD 到就砸"，蓄能脉冲是**可见的蓄力过程 + 释放瞬间的强反馈**，玩家的决策是"什么时候开始蓄"（例如精英冲锋前）。

## 5. 四技能定位对照（开发时以此验收）

| 技能 | 主要作用 | 不适合 | 数值重心 |
|---|---|---|---|
| 环刃 | 贴脸清杂兵、防身 | 打 BOSS / 远程怪 | 持续 DPS |
| 地雷阵 | 预布置、拖住怪群 | 追击快速目标 | 单次爆发 + 上限 4 |
| 哨戒哨兵 | 持续补伤害、解放走位 | 需要爆发时 | 稳定 DPS |
| 蓄能脉冲 | 精英/BOSS 攻坚 | 清小怪 | 单体高爆发 |

### 特殊（S）规则明细

- orbit × 环刃：环绕弹额外 +1 片，但受"最多 4 片"上限约束；
- split × 地雷阵：地雷引爆时额外炸出 2 枚小子弹（伤害 40%），衍生物不再分裂；
- echo × 地雷阵：重放只允许 1 次（否则雷区会瞬间铺满 4 枚上限）；
- echo × 蓄能脉冲：重放**不重新蓄力**，直接以已蓄满数值结算一次；
- vamp × 哨兵：哨兵伤害可以为玩家回血，但来源仍为 summon（不触发玩家 onhit 模块）。

### 哨兵（召唤物）专项规则

1. 哨兵弹体伤害来源 = summon，**不触发玩家任何 onhit 模块**；
2. 明确允许的弹体类模块（multi/fan/pierce/bounce/split/snipe/burn/frost/chain/thunder/vamp）作用于**哨兵的弹体**，但只按哨兵自己的伤害计算；
3. 哨兵**不能被 multi/split/echo 复制自身**（同时只有 1 个）；
4. 召唤物击杀计入玩家击杀数，但 killblast / harvest 的触发规则以"来源 summon 不触发模块"为准（harvest 属 kill 钩子，按 v5 规则**仍可回血**，需在实现时显式确认）。

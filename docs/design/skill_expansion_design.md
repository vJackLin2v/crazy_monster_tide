# 新技能设计（skill_expansion_design）

> 第一批 4 个正式新增 + 4 个候选。每个技能都带来**新的战斗行为**，不是换数值。

## 第一批（4 个）

### 1. orbit_blades 环刃回旋

| 字段 | 值 |
|---|---|
| type | orbit（新增） |
| tags | physical, orbit, melee |
| 伤害 / 冷却 | 6 / 1.8s（持续存在） |
| 范围 | 玩家周围 38px 环形 |
| 目标规则 | 环形带内所有敌人（每 0.25s 判定一次） |
| 行为 | 2 片刀刃绕玩家旋转，转速 1.4 圈/秒 |
| 成长 | 每级 +1 片（最多 4 片），伤害 +22%/级 |
| 兼容 | calc 类仅 giant（半径）、rapid（转速）有效；multi/fan/split 无效（无弹体） |
| 弱点 | 只有贴脸才打得到；对远程怪零作用 |
| 性能 | 2~4 片 × 每 0.25s 一次圆形判定，成本低 |

### 2. mine_field 地雷阵

| 字段 | 值 |
|---|---|
| type | trap（新增） |
| tags | physical, trap, area |
| 伤害 / 冷却 | 22 / 2.6s |
| 行为 | 在玩家脚下放 1 枚地雷，落地 0.6s 后进入待触发；敌人踩到（半径 16）爆炸 44px |
| 上限 | 同时存在 **4 枚**，超出的最早一枚立即引爆 |
| 成长 | 每级 +8 伤害、+6px 爆炸半径 |
| 兼容 | giant（半径）、burn（爆炸挂灼烧）有效；pierce/bounce/chain 无效 |
| 弱点 | 需要预判走位；对快速移动怪命中率低 |
| 性能 | 4 枚静态实体，每帧距离检测 4×N，可接受 |

### 3. sentry 哨戒哨兵

| 字段 | 值 |
|---|---|
| type | summon（新增） |
| tags | arcane, summon, projectile |
| 伤害 / 冷却 | 5 / 1.2s（哨兵每 0.9s 自动射一发） |
| 行为 | 在玩家当前位置放一个哨兵，持续 8s，自动攻击最近敌人 |
| 上限 | 同时 **1 个**（重复施放刷新位置与持续时间） |
| 成长 | 每级 +1.5 伤害、+0.6s 持续 |
| 兼容 | multi/fan/snipe/rapid 作用在哨兵的弹体上；orbit/trap 无效 |
| 弱点 | 哨兵不移动，怪群会绕开；本体死亡后哨兵仍在 |
| 性能 | 1 个哨兵 × 每 0.9s 一发，成本极低 |

### 4. charge_pulse 蓄能脉冲

| 字段 | 值 |
|---|---|
| type | charge（新增） |
| tags | lightning, area, charge |
| 伤害 / 冷却 | 30 / 4.0s（**前 3 秒蓄力，第 4 秒释放**） |
| 行为 | 蓄力期间脚下出现光圈（视觉预警），释放时对 90px 内全部敌人造成伤害并眩晕 0.4s |
| 成长 | 每级 +6 伤害、+8px 半径、蓄力时间不变 |
| 兼容 | giant / overload 有效；echo 会让它连放两次（需上限 1 次） |
| 弱点 | 蓄力期是输出真空；怪少时收益低 |
| 性能 | 单次大范围判定，成本低 |

## 第二批候选（4 个，先不开发）

| id | 名称 | 行为 | 为什么先不做 |
|---|---|---|---|
| counter_aura | 反击光环 | 受击时反弹一圈伤害（0.5s 内置 CD） | 需要 onhurt 钩子，和 thornmail 有重叠风险 |
| staged_meteor | 裂空陨星 | 落点爆炸 0.8s 后二次爆炸 | 与陨石定位接近，需要先验证差异感 |
| frost_prison | 冰封牢笼 | 定身 1.2s（BOSS 免疫） | 控制过强，需要先定 BOSS 抗性规则 |
| boomerang_axe | 回旋战斧 | 飞出后返回，返程伤害 120% | 与回旋刃重叠，除非改成"穿透 + 返程" |

## 与现有系统的兼容检查

- 新增 4 个 type 需要在 Battle 里加 update 分支；
- 每个新 type 必须有**实体上限**（orbit 4 片、trap 4 枚、summon 1 个、charge 1 个）；
- canInstall 需要为无弹体技能补"哪些模块无效"的提示文案；
- 图鉴需要新分类筛选：orbit / trap / summon / charge。

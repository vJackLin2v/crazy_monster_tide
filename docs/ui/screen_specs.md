# 竖屏规格（尺寸 / 安全区 / 热区 / 层级）

## 1. 逻辑分辨率 `[定]`

| 项 | 值 |
|---|---|
| 设计分辨率 | **360 x 640**（竖屏） |
| 官方基准 | 微信小游戏设计指南建议 **750 x 1334**；本工程 = 官方基准 x **0.48**（完全同比例） |
| 适配策略 | fitWidth（宽度铺满，高度溢出裁剪 / 延伸） |
| 纹理过滤 | Nearest |
| 坐标系 | 以设计分辨率下左为原点；实现时按引擎适配层换算 |

## 2. 版面分区（自上而下）

```
+--------------------------+
| 顶部状态区  HP / EXP / 等级 / 暂停 |
+--------------------------+
| 战斗可视区（像素舞台）              |
|   技能状态栏（4 图标 + 行为槽缩略）  |
|                                   |
+--------------------------+
| 底部输入区（动态摇杆区域，不固定 UI）|
+--------------------------+
```

## 3. 触控热区

| 控件类型 | 最小热区 | 说明 |
|---|---|---|
| 主要按钮（开始 / 继续 / 选择卡） | >= 44 x 44 dp | 拇指可达 |
| 战斗内图标（暂停等） | >= 32 x 32 dp | 需留视觉留白 |
| 选择卡 | 整卡可点 | 卡间距 >= 8 dp，避免误触 |
| 顶部边缘 | 预留 >= 24 dp 安全区 | 规避系统手势 / 刘海 |

## 4. 多尺寸验证 `[定]`

至少在 **375x812 / 390x844 / 412x915** 三个竖屏视口验证：无溢出、无遮挡、热区不重叠。

## 5. Design Token（已实测落地）

来源：Möbelmon 截图像素量测（见 `docs/ui/reference-library/mobelmon-analysis.md` §2），
已在 `prototype-html/src/tokens.css` 落地。

| 语义 | 变量 | 值 | 用途 |
|---|---|---|---|
| 最深底 | `--bg-0` | `#0D1732` | 遮罩、深色区 |
| 主底 | `--bg-1` | `#17233D` | 全局背景 |
| 面板 | `--bg-2` | `#1E1E40` | 卡片、面板 |
| 面板亮 | `--bg-3` | `#233154` | 按钮底、HUD 底、地图节点 |
| 描边 | `--line` / `--line-2` | `#31456F` / `#3E5490` | 2px 硬描边 |
| **主强调** | `--accent` | `#FFA84B` | **唯一强调色**：CTA / 进度 / 可交互 |
| 强调暗 | `--accent-d` | `#E08020` | 按钮下沉阴影 |
| 辅助 | `--mint` | `#88D6BC` | 正向数值、经验 |
| 稀有 | `--purple` | `#6842A7` | 稀有物、场景 |
| 正文 | `--cream` | `#F7E9E0` | 文字、标题 |
| 危险 | `--red` | `#E04060` | 扣血、危险 |

**硬规则**：全屏**只有一个强调色**（橙）；其余元素一律压低对比。

| 尺度 | 值 |
|---|---|
| 圆角 | 6 / 10 / 16 px |
| 间距阶梯 | 4 / 8 / 12 / 16 / 24 px |
| 字号阶梯 | 11 / 13 / 16 / 20 / 26 px |
| 卡片投影 | `0 6px 0 rgba(0,0,0,.35)`（硬投影，非模糊） |
| 主要热区 | >= 44x44 dp；战斗内图标 >= 32x32 dp |

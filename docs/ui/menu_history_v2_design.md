# 主菜单 / 战绩 V2 设计（menu_history_v2_design）

> 360×640；坐标是设计坐标（y 从屏幕顶算），实现用 `at()` + `safeTop()/safeBottom()`。
> 组件复用 `UIKit`（panel/button/text/onTap）+ `ModalList`；素材见 `menu_history_v2_asset_inventory.md`。

## 1. 主菜单 V2

### 1.1 分区（S = safeTop）

| 区域 | y 范围 | 内容 |
|---|---|---|
| A 品牌 | S ~ S+80 | 「疯狂鸽王」34px + 英文副标 8px |
| B 角色展示 | S+86 ~ S+268 | 立绘 116×136 + 像素平台 + 名称 16 + 一句角色特性 + 解锁数；点击进选角（仅更换展示） |
| C 核心操作 | S+270 ~ S+420 | 有存档：继续卡 300×96 + 开始新冒险 270×46；无存档：开始冒险 270×58 + 提示 |
| D 次级入口 | S+416 ~ S+520 | 战绩/图鉴/成就/设置：4 × (84×72)，图标槽 44×44 + 10px 文字；下方玩法说明 160×30 |
| E 页脚 | VH-B-20 | 版本号 8px |

### 1.2 继续卡（有存档）

- 300×96 面板 + 左侧 5px accent 条；
- 第 1 行「继续上次冒险」16px accent；
- 第 2 行「第 12/20 波 · 困难」11px；
- 第 3 行「生命 45/72 · 12:35 · 10/31 15:15」9px dim；
- 第 4 行「构筑：技能 3 · 道具 5 · 环刃/哨兵」9px accent；
- 右侧「继续 ▶」；
- 整卡点击 = 继续。

### 1.3 无存档

- 不显示灰卡；直接 270×58「开始冒险」主按钮 + 一句提示。

### 1.4 开始新冒险（有存档）

- 点击「开始新冒险」→ 三选弹窗：
  - 继续当前冒险（primary）
  - 放弃并开始新游戏（会写一条 abandoned 历史）
  - 返回
- 不允许静默覆盖存档。

### 1.5 存档损坏 / 版本不符

- 卡片显示「存档不可用」+ 具体原因 + 「点此清除坏档」；
- 下方仍可「开始冒险」。

## 2. 战绩档案（列表）

| 区域 | y | 内容 |
|---|---|---|
| 标题 | S+20 / S+44 | 「战绩档案」20px + 「记录每一次冒险」9px；左上返回 64×36 |
| 统计面板 | S+66 ~ S+142 | 330×76：总场次 / 胜利 / 最高波次 / 最长生存（数值 18px，标签 8px） |
| 筛选 Tab | S+146 ~ S+182 | 4 × 78×36：全部 / 胜利 / 失败 / 无尽 |
| 列表 | S+190 ~ VH-B-10 | 卡片 330×92，间距 8，ModalList 滚动 |

卡片：
- 左：52×52 立绘 + 角色名 14px + 难度·模式 9px；
- 中：波次 20px accent（无尽显示「25」+ 波次（无尽）），时间 11px + 击杀 9px；
- 右：结果文字（胜/败/无尽止步/主动放弃）+ 日期 8px + 「详情 ›」。

空态：320×260 面板 + 64×? 立绘 + 文案 + 「开始第一场冒险」按钮（直接进难度页）。

## 3. 对局详情（单局报告）

| 区块 | 内容 |
|---|---|
| 头图 | 结果大字（成功通关 / 挑战失败 / 无尽落幕 / 主动结束冒险）+ 难度·结果·模式 + 立绘 + 角色名 + 波次/时长 + 起止时间 |
| 核心数据 | 2×3 面板（158×56）：击杀 / 生存 / 最高波次 / 造成伤害 / 承受伤害 / 获得金币；缺失显示「未记录」 |
| 技能构筑 | 每技能 330×48：32 图标 + 名称 Lv + 黑科技数量 + 「详情 ›」；点击弹层显示技能描述与已装黑科技 |
| 道具收藏 | 7 列 42×42 图标 + ×N；空时一行说明 |
| 关键事件 | 最近 12 条里程碑；无记录时说明 |

## 4. 交互状态

| 页面 | 状态 |
|---|---|
| 主菜单 | 有存档 / 无存档 / 损坏 / 版本不符 / 开新确认 |
| 列表 | 空历史 / 筛选为空 / 单条 / 多条 / 50 条 / 滚动 / 返回保持筛选与位置 |
| 详情 | 胜利 / 失败 / 放弃 / 无尽 / 字段缺失降级 |

## 5. 视觉

- 面板：现有 `panel` 九宫格 + 硬投影，不用毛玻璃；
- 主按钮唯一高对比橙色；次按钮同一套暗色；
- 次级入口 = 图标槽 + 短字，视觉权重明显低于继续/开始；
- 结果色：胜利 mint / 失败 red / 无尽 accent / 放弃 dim。

# 竖屏小游戏 UI 总原则

## 1. 单手可玩 `[定]`

- 主要操作区在**屏幕下半部**，拇指可覆盖。
- 动态摇杆：触点落下处生成，松开即消失；**不固定**绘制摇杆。
- 关键按钮不放屏幕顶部边缘（避免系统手势区冲突）。

## 2. 战斗期极简 `[定]`

- 战斗中**不出现大块技能按钮**（技能自动释放，无需操作）。
- 顶部信息：HP、经验、等级、暂停。
- 技能状态栏：4 个技能图标，每个下方显示 <=3 个行为槽缩略标识。
- 底部主要作为移动输入区域。

## 3. 可读性优先（像素风约束）

- 纹理过滤 **Nearest**，禁止模糊缩放。
- 像素素材尽量整数倍缩放（非整数缩放会导致抖动 / 糊边）。
- 战斗信息（伤害数字 / 状态图标）在怪潮背景下必须仍可辨。
- 深色底 + 高对比描边是本作的默认可读性手段。

## 4. 触摸优先

所有主要交互必须同时考虑：鼠标、触摸、长按、拖拽、小屏、页面滚动干扰。

## 5. 反馈即信息

任何一次玩家操作与系统结算都必须有可见反馈（视觉 / 音效 / 数字 / 屏震至少一项）。

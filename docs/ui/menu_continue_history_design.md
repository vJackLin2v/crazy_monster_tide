# 主菜单升级 UI 设计（menu_continue_history_design）

> 画布 360×640 竖屏；坐标是**设计坐标**（y 从屏幕顶算），实现里用 `at()` + `safeTop()/safeBottom()` 转节点坐标。
> 组件全部复用 `ui/UIKit`（panel / button / text / screenHeader）与 `ui/ModalList`（滚动）。

## 1. 主菜单

### 1.1 布局（设计坐标）

| 元素 | x | y（中心） | w | h | 说明 |
|---|---:|---:|---:|---:|---|
| LOGO「疯狂鸽王」 | 180 | S+56 | 354 | — | 38px 粗体，黑描边 |
| 英文副标 | 180 | S+92 | 354 | — | 9px accent |
| 继续游戏卡片 | 180 | S+180 | 300 | 78 | 全页最高优先级 |
| 开始游戏（CTA） | 180 | S+284 | 270 | 54 | 唯一橙色按钮 |
| 玩法说明 | 180 | S+358 | 270 | 44 | 独占一行 |
| 历史对局 | 180 | S+422 | 270 | 44 | 独占一行，次主入口 |
| 图鉴 | 72 | S+484 | 100 | 46 | 三个一行 |
| 成就 | 180 | S+484 | 100 | 46 | |
| 设置 | 288 | S+484 | 100 | 46 | |
| 版本/说明 | 180 | min(S+530, VH-B-12) | 200 | — | 9px dim，居中 |

- 层级：继续卡（有存档时 accent 描边 + 左侧 5px 高亮条）> 开始游戏（橙色，独占一行）> 玩法说明 / 历史对局（各独占一行）> 图鉴 / 成就 / 设置（一行三个）。
- 背景沿用 `home-bg-360x640` + 上下 8 段暗角色带（像素风，不用模糊渐变）。

### 1.2 继续卡片状态

| 状态 | 触发 | 视觉 |
|---|---|---|
| 有存档 | `saveState='ok'` | 左侧高亮条 + 「▶ 继续游戏」；第 2 行 `第 12/20 波 · 困难`；第 3 行 `生命 45/72 · 00:08 · 10/31 15:15`；第 4 行 `构筑：环刃 / 哨兵`；右侧 `»` |
| 无存档 | `saveState='none'` | 灰条 + 「继续游戏」暗色；说明「当前没有未完成的对局」「开始新游戏，开启新的冒险」；点击只在卡内提示「还没有存档」，**不启动新游戏** |
| 存档损坏/版本不符 | `saveState='corrupt'` | 红字说明原因（如「存档版本过旧（v0）」）+「点这里清除坏档」；点击清档并刷新菜单 |

### 1.3 返回主菜单确认（三选）

- 标题「返回主菜单？」+ 副标「保存后可以从主菜单『继续游戏』接着打」。
- 按钮：**保存并退出**（primary）/ 放弃本局（写入历史）/ 继续游戏（取消）。
- 三种结果的数据路径见 `run_save_and_history_design.md` §5。

## 2. 历史对局列表

### 2.1 布局

| 区块 | y（顶） | 内容 |
|---|---:|---|
| 标题条 | S（高 54） | 「历史对局」+ 左上「返回」（64×36，条心 S+27） |
| 总览 | S+58 | `总对局 N　胜利 N　最远 N 波　最长 mm:ss`（11px） |
| 筛选 | S+88 | 4 个 76×32：全部 / 胜利 / 失败 / 无尽；当前项 primary |
| 列表视口 | S+132 ~ VH-B-12 | ModalList 滚动，行高 96 + 间距 8 |

### 2.2 单行（330×96）

- 左：44×44 角色头像框（角色名首字，避免列表加载立绘）。
- 第 1 行：角色名（14 粗）+ 右侧「难度 · 结果」（结果色：胜利 mint / 失败 red / 无尽 accent / 放弃 dim）。
- 第 2 行：`第 12/20 波 · 08:36 · 击杀 185`。
- 第 3 行：最终技能（最多 3 个，accent）。
- 右侧：日期（9px）+「查看详情 >」。
- 点击整行进入详情；拖动超过 8px 不触发点击（`ml.isDragging()`）。
- **返回列表时保持筛选与滚动位置**（ModalList `offset()` → 重建时传入 `initialOff`）。

### 2.3 空状态

- 无任何记录：卡片「还没有历史对局 / 完成一场冒险后，这里会记录你的战斗经历。」
- 有记录但当前筛选为空：「这个筛选下没有对局 / 换一个筛选看看」。

## 3. 历史详情

- 顶部标题条 + 返回；正文为纵向滚动（ModalList，内容高度按区块累计计算）。
- 模块顺序：
  1. **基本信息**：52×52 头像、角色名、难度·结果（·无尽）、开始→结束时间。
  2. **四个统计卡**（2×2，160×58，中心 ±84 居中）：到达波次 / 存活时间 / 击杀数量 / 徽章数。
  3. **战斗统计**：左 Key / 右 Value 的行式布局（Key 10px dim 左对齐，Value 12px 粗体右对齐）：
     精英击杀 / BOSS 击杀 / 获得金币 / 商店花费 / 结束生命（未记录显示「未记录」）。
  4. **技能构筑**：每技能 330×46，名称 + Lv + 已装黑科技名。
  5. **道具收藏**：7 列 40×40 槽位 + ×N 角标；空时显示「（本局没有获得道具）」。
  6. **对局进程**：最近 12 条里程碑（进入波次 / BOSS 出现·击败 / 传说 / 无尽）。
  7. **结束原因**：通关 / 被击败 / 无尽倒下 / 主动放弃，卡片 330×58。
- 详情缺失（旧记录/数据损坏）时用摘要降级显示，不白屏。

## 4. 交互与适配

- 所有按钮热区 ≥44×44；历史页「返回」为 64×36 的视觉按钮，中心与标题条条心对齐（S+27，条高 54），不压标题文字。
- 安全区：标题避让 `safeTop()`，列表底部避让 `safeBottom()`。
- 长列表只构建可视内容（ModalList 内部按 contentH 定位，不逐帧计算）。
- 页面切换统一 `clearScreen()`，ModalList 的 Mask/事件随节点销毁。

## 1. 设计系统（与 `prototype-html/src/tokens.css` 一一对应）

| 语义 | 变量 | 值 |
|---|---|---|
| 最深底 | `--bg-0` | `#0D1732` |
| 主底 | `--bg-1` | `#17233D` |
| 面板 | `--bg-2` | `#1E1E40` |
| 面板亮 | `--bg-3` | `#233154` |
| 描边 | `--line` / `--line-2` | `#31456F` / `#3E5490` |
| **主强调（唯一）** | `--accent` | `#FFA84B` |
| 强调暗 | `--accent-d` | `#E08020` |
| 辅助 | `--mint` | `#88D6BC` |
| 稀有 | `--purple` | `#6842A7` |
| 正文 | `--cream` | `#F7E9E0` |
| 危险 | `--red` | `#E04060` |

**硬规则**
1. 全屏**只有一个强调色**（橙）：CTA / 进度 / 可交互。
2. 卡片与按钮：2px 硬描边 + `box-shadow: 0 Npx 0` 硬投影（**不用模糊阴影**）。
3. 圆角 6 / 10 / 16 px；间距 4 / 8 / 12 / 16 / 24；字号 11 / 13 / 16 / 20 / 26。
4. 纹理过滤 Nearest；像素素材整数倍缩放。
5. 遮罩统一 `rgba(5,8,15,.74)` + `backdrop-filter: blur(1.5px)`。

## 3. 关键交互规格

| 交互 | 规格 |
|---|---|
| 动态摇杆 | 触点落下处生成 96x96 摇杆；有效半径 34px；松开/取消/失焦即消失；`touch-action:none` 防浏览器抢手势 |
| 移动 | 角色移速 = `62 x 角色倍率 x 道具加成`；方向向量归一化，力度按拖动距离线性 |
| 技能 | **全自动**：索敌半径 260px（投射物）/ 全屏取最密集（区域与脉冲）；无手动按钮 |
| 升级 | 经验满 → 自动暂停 → 模态 3 选 1；选到模块 → 进入安装步骤 → 装完自动回战斗 |
| 暂停 | 右上 `II` → 遮罩 + Build 抽屉；「继续」回战斗 |
| 波间 | 倒计时归零 → 自动清场 → 进商店；「下一波」进下一波 |
| 第 20 波后 | 商店出现「收工结算」+「继续挑战」（无尽） |
| 热区 | 主按钮 ≥44x44 dp；战斗内图标 ≥32x32 dp；卡片整卡可点 |

## 5. 文案基线

- 战斗行：`第 N 波 · 剩 Xs · 击杀 Y`｜BOSS 波：`第 N 波 · BOSS`
- 结算：`通关！` / `倒下`；统计项：存活时间 / 击杀 / 等级 / 推进到 / 金币 / seed
- 商店：`刷新 ◆X`、`下一波`、`继续挑战`、`收工结算`
- 升级：`升级！`、`从下列 3 项中选择 1 项`、`跳过（+8 金币）`
- 数值格式：百分比整数（`+12%`）、生命（`100/120`）、冷却（`0.85s`）

## 6. 变更流程

本文件一旦获得用户确认并改名为 `ui-spec-approved.md`：

1. **不得**再凭感觉改布局；
2. 任何 UI 变更需先改本文件（或开新版本），再改实现；
3. 已实现页面只在后续任务涉及它时按 `ui_capability_protocol.md` 流程逐步改善，不推倒重来。

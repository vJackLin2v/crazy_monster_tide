# 优化落地结果（2026-10-13 完成）

## 量化指标变化

| 指标 | 参考作品 | 我们(优化前) | 我们(优化后) |
|---|---|---|---|
| **中调像素%**（"画面有内容"） | 26.7~34.5% | **3.7%** | **19.4%**（5.2 倍）|
| 暗底% | 57~68% | 95.2% | 79.0% |
| 霓虹% | 1.1% | 1.1% | 1.5% |
| 帧率 | — | 60.2 | **60.2**（无掉帧）|

## 三项优化

### 1. 地面层次（碎石 + 中大型物件）
程序生成、确定性哈希（不会每帧闪）：
- 碎石：7~11 个/格、3~7px，四种色调（碎石/亮碎石/草簇/裂缝）
- 中大型物件：40% 的 2x2 块、10~24px，带暗底阴影做出立体感
- 效果：中调 3.7% → 20.1%

### 2. ★ 单位黑色描边（关键修复）
**问题**：地面加密后，VLM 两次提醒「角色和怪物颜色与地面接近，很难分辨」→ 裁图确认属实。
**做法**：单位节点重构为「容器 + 三层子节点」：

```
node (容器，Battle 定位/翻转)
  ├─ outline  黑色剪影（放大 1.14，垫底）
  ├─ shadow   脚下软阴影
  └─ body     动画精灵（FrameAnim 挂这里）
```

**⚠️ 必须这样分层**：Cocos 里「节点自身的 Sprite 先于子节点渲染」——
把描边做成子节点、精灵挂在容器上，描边会**盖到精灵上面**。
连带修：受击闪白要从 `body` 取 Sprite（容器上没有组件）。

### 3. 特效分层（参考的"闪光+粒子+碎片"）
| 时机 | 层数 | 内容 |
|---|---|---|
| 命中 | 2~3 | 技能专属命中特效 + 通用火星 + 暴击时闪光 |
| 击杀 | 3~4 | 爆发 + 碎片 + 尘土（+ 精英/BOSS 冲击波环）|

每层给不同尺寸/寿命/微偏移，避免完全重叠显得假。

**踩坑**：`addVfx` 是**同步**取帧的，新加的特效层必须加进预载列表，
否则**静默不显示**（会让人误以为分层没生效）。

## 最终 VLM 复核（原话）

- **「右边的画面更饱满、更有完成度」**
- **「右边的角色和怪物更容易辨认…轮廓更加清晰，颜色对比更鲜明」**
- **「右边和左边的观感差距已经大大缩小」**

**剩余短板**（VLM 指出）：光影效果、背景细节深度、纹理与阴影处理。

## 下一步建议

2. UI 四角化（参考把信息分散到四角，中心视野完全留白）
3. 地面细节继续往 25%+ 推

# 热门小游戏 UI 调研（2026-10-13）

> 用户要求：「先去搜索几款热门小程序，看看别人的比例和UI，再对该项目进行修改」

## 调研方法

- Bing **文本**搜索对中文多词查询分词有问题（"手机游戏" 被拆成 "手机"）；引号精确匹配游戏名可用
- Bing **图片**搜索按字面匹配关键词（搜"弹壳特攻队"返回枪弹壳、"向僵尸开炮"返回变压器）→ **不可用**
- **百度图搜可用**：`https://image.baidu.com/search/index?tn=baiduimage&word=<词>`
  - 提取 `img.main_img` 的 src + 页面内 `objURL` 字段
  - 下载 6 张真实竖屏截图（弹壳特攻队 3 张、向僵尸开炮 2 张）

## 量化结果：UI 占屏比例

用"逐行细节密度"检测 UI 带（阈值取该图细节量的 35% 分位 x1.35）：

| 游戏 | 顶部 UI | 底部 UI | **游戏区** |
|---|---|---|---|
| 弹壳特攻队 A | 0% | 15.0% | **85.0%** |
| 弹壳特攻队 B | 0% | 0% | **100%** |
| 向僵尸开炮 A | 0% | 7.5% | **92.5%** |
| 向僵尸开炮 B | 5.0% | 12.5% | **82.5%** |
| **本工程（改前）** | 7.5% | **22.5%** | **70.0%** |
| **本工程（改后）** | ~6% | ~9.5% | **~84%** |

> ⚠️ 该算法在**棋盘格地面**上会误判（格子纹理也算"细节"）——
> 对参考游戏截图（纯色/渐变地面）可用，对本工程要**用节点级测量**核实
> （实测技能栏距底 8px、高 64px → 底部 UI 9.5%）。

## 视觉结论（VLM 读图）

1. **底部技能图标下面没有文字说明** —— 只有图标 + 模块小方块
2. **技能图标较大**，占满宽度
3. **顶部数值文字直接显示、相对较大**，颜色鲜艳对比度高
4. 整体界面简洁，游戏区不被 UI 挤压

## 据此对本工程做的修改

| 改动 | 依据 |
|---|---|
| 删掉技能栏下方的技能名 | 参考游戏都没有 |
| 技能图标 44 -> 52，槽宽 52 -> 56 | 参考"图标较大" |
| HP 数字 9 -> 12（加粗+黑描边） | 参考"数值大、看得清" |
| 等级/金币/波次 11 -> 13 | 同上 |
| 暂停面板按钮移回面板内（-288 -> -244） | 原来按钮底边 -312 比抽屉底边 -280 低 32px |
| 暂停面板加「装模块」按钮 | 见下 |
| **补上模块安装流程** | 原来选到模块只是 `modsBag.push()`，**没有任何安装入口** |

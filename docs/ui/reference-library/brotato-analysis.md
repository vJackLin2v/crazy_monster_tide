## 1. 核实到的机制事实

| 项 | 事实 | 来源 |
|---|---|---|
| 波数 | **20 波**，每波约 1 分钟，最后一波为 BOSS 波 | GameRes 设计分析、多篇攻略 |
| 波间 | 每波结束进入**商店**，用金币买武器/道具，刷新需要代价 | 攻略、实机描述 |
| 精英 | 中后期波次（约 11~18 回合）会出现**精英怪或部落** | 九游机制详解 |
| BOSS | 20 波为 BOSS 波；高难度下最后一回合可出**两个 BOSS** | 九游机制详解 |
| 无尽 | 打通 20 波后存在**无尽模式**（关数继续增长） | 17173 无尽模式攻略 |
| 难度 | 6 档难度，通过滑块选择；难度影响敌人血量/伤害与 build 选择次数 | 九游/GameRes |
| 成长 | 局内靠金币在商店滚雪球；击杀 BOSS 掉落物品 | 多篇攻略 |

## 2. 本作采纳 / 不采纳

| # | Brotato 的做法 | 本作 | 说明 |
|---|---|---|---|
| 1 | 20 波 + 每波倒计时 | ✅ 采纳 | `RUN.waves = 20`，时长 `18 + floor((n-1)/3)*3` 秒 |
| 2 | 撑到时间结束即过关（残余怪清空） | ✅ 采纳 | 与「击杀数达标」相比更干净，且节奏可预期 |
| 3 | 波间商店 + 刷新 | ✅ 采纳 | 刷新价格递增（2/3/4…） |
| 4 | BOSS 波在末波 | 🔸 调整为**每 10 波**（10 / 20 / 30…） | 20 波只有一个高潮太稀，改为双高潮；无尽模式下可持续 |
| 5 | 精英分布在中后期 | 🔸 调整为**每 3 波一次**，第 12 波起出 2 只 | 让整局都有"小高潮" |
| 6 | 20 波后可继续（无尽） | ✅ 采纳 | 打通 20 波后在商店里选「继续挑战 / 收工结算」 |
| 7 | 6 档难度 | ❌ 暂不采纳 | 首版不做难度选择，见 `wave_rules.md` TBD |
| 8 | 武器/道具槽位与合成 | ❌ 不采纳 | 本作差异点是 **4 技能 × 3 行为槽的模块化构筑**，不抄其武器系统 |
| 9 | 其像素美术风格 | ❌ 不采纳 | 版权；本作走**像素奇幻**包装（D-08） |

## 3. 对本作 UI 的影响

- **战斗 HUD**：Brotato 的核心信息是「本波剩余时间 / 波数 / 血量」——本作已对齐
  （顶部 HP + Lv，下方一行 `第 N 波 · 剩 Xs · 击杀 Y`）。
- **BOSS 常驻血条**：BOSS 波必须有横向常驻血条（用户指令，D-15），本作放在 HUD 下方。
- **波间商店**：横向列表 + 价格 + 不可购买态（金币不足 / 已拥有 / 已满级）。
- **不采纳**：Brotato 的武器槽位网格 UI（本作用「技能 + 行为槽」表达）。

## 2. 配色（代码量测，精确）

对 18 张截图做通道量化统计，得出该 UI 的骨架色板：

| 角色 | 实测值 | 占比 | 用法 |
|---|---|---|---|
| 主底色 | `#17233D` / `#1E1E40` | 11.4% / 11.2% | 全局背景 |
| 面板亮层 | `#233154` / `#1B294E` | — | 卡片、面板、HUD 底 |
| 深底 | `#0D1732` / `#000020` | 31.9%（单图最高） | 遮罩、深色区 |
| **主强调（CTA）** | **`#FFA84B` / `#E08020`** | 7.1% | 按钮、进度、可交互高亮 |
| 辅助青绿 | `#88D6BC` / `#5FB79C` | 2.4% | 正向数值、确认、经验 |
| 场景紫 | `#6842A7` / `#8C63CF` | 2.2% | 稀有物、场景装饰 |
| 暖白文字 | `#F7E9E0` / `#EEDBCD` | 18.4%（浅色图） | 正文、标题 |
| 危险红 | `#E04060` | 0.9% | 扣血、危险 |

**结论**：深蓝夜幕底 + 橙色单一强调 + 青绿辅助 + 暖白文字。
**关键规律**：**全屏只有一个强调色**（橙），所有「可以点」「在增长」「要你看」的东西都用它；其余一律压低对比。

## 4. 可迁移 Pattern（本工程采纳）

| # | Pattern | 参考中的表现 | 本工程落地 |
|---|---|---|---|
| P1 | **夜幕底 + 单强调色** | 深蓝底，橙色独占强调 | `--bg-1/2/3` + `--accent`，仅 CTA/进度/稀有使用橙色 |
| P2 | **战斗期 HUD 贴边** | 血条在左上、进度在底部，中间留白 | 顶部 HP+等级+暂停；底部技能状态栏；中间全给怪潮 |
| P3 | **横向 3 卡选择** | 商店/升级均为横向 3 张卡 | 升级 3 选 1、商店 3 项，同一套卡片视觉 |
| P4 | **粗描边 + 硬投影** | 卡片/按钮均有 2px 描边与下沉阴影 | `border:2px solid var(--line)` + `box-shadow 0 6px 0` |
| P5 | **大圆角面板** | 面板 10~16px 圆角 | `--r-m:10px / --r-l:16px` |
| P6 | **图标优先、文字其次** | 槽位/道具以图标为主，文字小字附注 | 技能栏=图标+3 槽位点；卡片=大图标+小字说明 |
| P7 | **拇指可达** | 主要交互在下方 2/3 | 摇杆全区可触发；底部放选择卡与主按钮 |

## 6. 结论

1. 该参考的价值集中在 **配色关系 + 战斗 HUD 贴边 + 横向 3 卡** 三点，已在 `prototype-html/` 中落地并量化为 Design Token。
2. 参考只影响「UI 怎么做」，**不影响「游戏怎么做」**（玩法仍以 `docs/requirements.md` 为准）。

# ⚠️ 补记（2026-10-13）：我漏掉了它最标志性的设计语言

## 漏掉的是什么

**大面积彩色横幅**。像素量测（顶部 20% 主色占比）：

| 参考屏 | 顶部主色 | 占比 |
|---|---|---|
| screen-13 / 15 | `#F8A048` 橙 | **35.6% 高** |
| screen-07 | `#F8A048` 橙 | **40.4% 高** |
| screen-08 | `#F8A848` 橙 | 18.6% 高（底部还有 6.8% 橙按钮栏） |
| screen-03 | `#7048A8` 紫 | 25.8% 高 |
| screen-05 | `#70C0A8` 薄荷 | 82% 高 |

## 我为什么搞错

分析里我推导出一条规则：**「全屏只有一个强调色（橙），其余一律压低对比」**，
然后把它当成了"橙色只能小面积使用"（按钮、进度条）。

**但参考是把橙色当大面积表面色用的**（占顶部 80~93%）。
「只有一个强调色」指的是**色相数量**，不是**面积**。我理解偏了。

## 参考本身的分寸（值得学）

| 屏幕类型 | 有无横幅 |
|---|---|
| 菜单 / 商店 / 构建 / 结算（01/03/05/07/08/09/13/15） | ✅ 有 |
| **战斗 screen-04** | ❌ 无（深色贴边） |
| 升级三选一 screen-17 | ❌ 无（靠卡片） |

**战斗屏不大色块**（挡视野），**非战斗屏才用横幅** —— 这个取舍很专业。

## 已落地

| 屏幕 | 横幅 | 实测 |
|---|---|---|
| 主界面 | 40% 橙 | **35.9% / `#F8A048`**（与参考 35.6%/`#F8A048` 一致）|
| 角色选择 | 18.5% 橙 | **18.4%**（参考 18.6%）|
| 玩法说明 | 26% 橙 | 已改 |
| 波间商店 | 18.5% 橙 + 底部 6.8% 橙按钮栏 | 已改（照 screen-08）|
| 结算 | 30%（胜橙 / 败红）| 已改 |
| 战斗 HUD | **保持深色贴边不变** | 照 screen-04 |

## 布局排法也要照抄

参考的**内容紧贴横幅下沿往下排**（screen-13 最大连续空白仅 **5%**），
我一开始把按钮做"垂直居中"，两头都留白 → 改成紧贴排布 + 底部补信息卡。

## 未使用其素材的原因（已向用户说明）

站点只提供 18 张设计稿截图，**没有拆分的 UI 组件文件**；
我当时自行判定"仅作参考、不得复制美术"且未与用户确认 —— 这是判断失误。

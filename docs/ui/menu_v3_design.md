# 主菜单 V3 设计（极简 + 像素功能图标）

> 360×640；坐标是设计坐标（y 从屏幕顶算），实现用 `at()` + `safeTop()/safeBottom()`。
> 本轮只改主菜单与设置入口；历史列表/详情保持 V2，不改数据与战斗。

## 1. 删除的内容（从主菜单移除）

- 角色立绘展示区、像素平台、角色特性描述、已解锁角色数量；
- 独立「玩法说明」大按钮（移入设置页）；
- 继续卡中的技能数量 / 道具数量 / 技能名列表；
- 底部版本号与多余说明文字；
- 「战/册/勋/设」汉字占位图标。

功能没有删除：角色选择仍在「开始冒险」后的流程里；玩法说明在设置页右上「玩法说明」。

## 2. 保留与新版布局

| 区域 | 位置 | 内容 |
|---|---|---|
| A 顶部 LOGO | 「疯狂鸽王」中心 S+40（32px），英文副标 S+64（8px） | 仅 LOGO + 副标 |
| B 中央操作 | 有存档：继续卡 **310×84**，中心 `max(S+200, VH×0.47)`；开始新冒险 **310×84（同尺寸）**，卡下 12 | 无存档：开始冒险 280×60，中心同区域 +6 |
| C 底部入口 | 入口中心 `VH-B-86`（相对上一版上移 22），图标 +8 / 标签 -26；四列 x=45/135/225/315，热区 84×72 | 战绩 / 图鉴 / 成就 / 设置 |

### 继续卡内容（三行）

1. 「继续冒险」18px + 像素三角箭头（Graphics 画的 3 段矩形，不是文字 ▶）；
2. `角色名 · 第 12/20 波 · 普通` 11px；
3. `生命 45/72 · 00:08` 10px dim。

> 2026-10-31 用户反馈后调整：继续卡与「开始新冒险」按钮统一为 310×84，间距 12；
> 底部四个入口整体上移 22px（`VH-B-86`）。

- 按下整卡缩放到 0.97，松手恢复；点击音由 `onTap` 统一播放。
- 卡下方「开始新冒险」明显更小；有存档时点击仍走三选确认（继续 / 放弃并开始 / 返回）。

### 无存档 / 损坏

- 无存档：不显示空卡，只显示「开始冒险」主按钮，不加解释文字。
- 损坏：保留「存档不可用 + 原因 + 点此清除」，下方仍可开始冒险；不伪装成无存档。

## 3. 底部功能入口

- 每个入口：32×32 像素图标（16×16 网格 ×2）+ 10px 标签，无大面积按钮底。
- 热区 84×72（≥44×44），按下缩放 0.97。
- 图标由 `ui/MenuIcons.ts` 用 Graphics 整数矩形绘制，详见 `menu_v3_icon_design.md`。

## 4. 设置页

- 右上新增「玩法说明」按钮（104×30），点击打开原玩法说明页，返回后回主菜单。
- 版本行改为左对齐、宽度收窄，避免被帮助按钮压住。

## 5. 不变的部分

- 继续/新局/放弃/历史/图鉴/成就/设置/角色选择/难度选择的数据与流程；
- 历史列表与详情（V2）；
- 战斗数值、技能/难度/奖励规则。

## 3. 关键交互规格

### 3.1 移动
- 动态摇杆：触点落下处生成 96x96，有效半径 34px，松开/取消/失焦即消失
- `touch-action:none`（防浏览器抢手势）
- 移速 = `96 px/s x 角色倍率 x 道具加成`

### 3.2 技能
全自动开火，无手动按钮。索敌：投射物取 260px 内最近；区域/脉冲取最密集点。

### 3.3 升级与安装（**槽位级交互**）
- 经验满 → 自动暂停 → 3 选 1
- 选到行为模块 → 安装屏：每个技能显示 3 个槽位按钮
  - **空槽** → 点击「空槽」直接装上
  - **已占用** → 点击该槽位（带「替换」角标）→ 换下原模块，**原模块退回背包，不损失**
  - 不兼容 / 已达叠加上限 → 该技能整行置灰并标注原因

### 3.4 技能替换（4 技能满时）
- 抽到新技能且已满 4 个 → 打开替换屏（列出 4 个已有技能，整行可点）
- 替换后：**被替换技能身上的所有行为模块退回背包**
- 可「放弃这个技能」返回

### 3.5 商店（参考 Brotato）
| 规则 | 规格 |
|---|---|
| 货位 | **固定 4 格**（空位显示"空货位"，列表不跳动） |
| 购买后 | **货位不消失**：保留原位置 + 盖「已购买」印记 + 整行置灰（解决"买完东西消失很怪"） |
| 锁定 | 每个货位右侧锁图标；**锁定的货位刷新不会被刷掉，并可留到下一波** |
| 刷新 | 花费金币，价格递增（2/3/4…）；已购买与已锁定不受影响 |
| 不可购买态 | 金币不足（价格置灰）/ 已拥有 / 已满级 —— **仍可见，只置灰** |

### 3.6 暂停与退出
- 右上 `II` → 遮罩 + Build 抽屉（4 页签）
- 抽屉左下 **[主菜单]** → **二次确认**（"本局进度会丢失"）→ 确认后清空本局并回主界面
- 战斗内图标（暂停键）为 32x32dp，**有意低于官方 44dp**（战斗视野优先），理由记录在
  `reference-library/wechat-minigame-guidelines.md` §3

## 5. 文案基线

- 战斗行：`第 N 波 · 剩 Xs · 击杀 Y`｜BOSS 波：`第 N 波 · BOSS`
- 升级：`升级！` / `从下列 3 项中选择 1 项` / `跳过（+8 金币）`；技能需替换时卡片标注 `技能（替换）`
- 安装：`空槽` / `替换` / `不兼容` / `已满级` / `选槽位`
- 替换：`技能已满 4 个` / `选择要替换掉的技能` / `放弃这个技能`
- 商店：`刷新 ◆X` / `下一波` / `继续挑战` / `收工结算` / `已购买` / `已拥有` / `已满级`
- 确认：`返回主菜单？` / `第 N 波的本局进度会丢失…` / `放弃本局`
- 结算：`通关！` / `倒下`；统计：存活时间 / 击杀 / 等级 / 推进到 / 金币 / seed

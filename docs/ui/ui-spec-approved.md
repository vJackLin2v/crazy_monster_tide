## 0. 这一版为什么这么定

用户指令（2026-10-15~17）：

1. UI **基准改动**：不再以 HTML DEMO 为唯一基准，改为**按土豆兄弟（Brotato）的 HUD 结构重新设计竖屏版**（D-35）。
2. HTML DEMO 只用于**早期定 UI 结构**；此后**不再用"复刻 DEMO"当验收标准**——
   因为 CSS 与 Cocos 渲染器不同，逐像素复刻不可达。
3. **跳过可玩 HTML 原型阶段**，设计稿定稿后**直接进 Cocos**（理由同上：DEMO 复刻不了，白做一遍）。
4. 参考边界（`ui_capability_protocol.md` §4.1）：Brotato 只作**布局/信息层级/视觉语言**参考，
   其美术、文案、图标、配色数值**一律不得照搬**。

## 5. 引擎落地注意（**这一节是给 Cocos 实现看的，重点**）

用户此前反馈「HTML 原型在 Cocos 复刻不了」。根因是**两边渲染器不同**，
所以本规格**不要求像素级复刻**，而是把每个效果都翻译成 Cocos 能做的动作：

| 设计稿里的效果 | Cocos 怎么做 | 能否做到 |
|---|---|---|
| 3px 纯黑描边 | `Graphics.lineWidth=3; strokeColor=黑; roundRect(); stroke()` | ✅ 完全一致 |
| **硬投影**（`0 4px 0 #000`） | 先画一个 **y 偏移 -4 的黑色圆角块**，再画本体。**不要用模糊阴影** | ✅ 完全一致 |
| 圆角 8 / 6 / 4 | `Graphics.roundRect(x,y,w,h,r)` | ✅ 完全一致 |
| 纯色填充 | `Graphics.fillColor + fill()` | ✅ 完全一致 |
| **竖直渐变**（血条/经验条） | 用 `UIKit.gradBar()`：**把条切成 10~18 条横带，逐条 `rect + fill`** | ✅ 近似（肉眼看不出） |
| **径向渐变**（主界面背景光晕） | 用 `UIKit.radialGlow()`：**画 14 个同心圆，逐层叠 alpha** | ✅ 近似 |
| 文字黑色描边 | `LabelOutline`（black, width 2） | ✅ |
| 文字向下硬投影 | 叠两个 Label（下层偏移 (0,-4)，黑色） | ✅ |
| 棋盘格地面 / 碎石纹理 | 已经是**程序化绘制**，不受影响 | ✅ |
| 字体 | Cocos 系统字体与 CSS 系统字体不同，**同字号看起来会略粗/略糊** | ⚠️ 允许差异，**不追求一致** |
| 字距（letter-spacing） | Cocos Label 不支持；需要时**逐字拆成多个 Label 手动定位** | ⚠️ 仅主标题需要，可拆字 |

**硬性要求**：
1. 所有 UI 用 `Graphics` 绘制（D-32），**不引入任何 UI 素材**。
2. 坐标必须锚定 `view.getVisibleSize()`，**不得写死 640**（见 KI-009：写死会导致整体悬空）。
3. 战斗 HUD 的**安全区 `y 101~562` 不得被任何元素侵占**（用户明确要求）。
4. 像素素材（单位 / 图标）**只允许整数倍缩放**，否则糊边。

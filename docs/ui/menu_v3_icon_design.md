# 主菜单 V3 功能图标设计（menu_v3_icon_design）

> 四个图标：战绩 / 图鉴 / 成就 / 设置。**全部为 16×16 像素网格绘制**，不使用汉字、Emoji、Unicode 符号或网页图标。
> 预览图：`docs/ui/menu_v3_icons_preview.png`（从真实运行截图裁切生成）。

## 1. 实现方式

- 文件：`cocos/assets/scripts/ui/MenuIcons.ts`
- 方式：Cocos `Graphics` + **整数网格矩形块**（每格 2×2 显示像素，最终 32×32），无曲线、无渐变、无抗锯齿。
- 自动居中：绘制前计算图形边界，平移到 16×16 网格中心。
- 调色板：
  - 米白 `#F4E7C6`（主体）
  - 金 `#F2B33D`（装饰 / 卷轴杆 / 书底）
  - 深蓝灰 `#2A3550`（阴影/描边，按需）
  - 橙 `#FFA84B`（强调，备用）
- 显示尺寸：32×32（2 倍整数放大），菜单标签 10px。

## 2. 四个图标

| 图标 | 语义 | 像素结构 |
|---|---|---|
| 战绩 History | 横向卷轴 / 记录 | 左右各 1 列金色卷轴杆 + 中间米白纸面 + 3 条记录横线 |
| 图鉴 Codex | 摊开的图鉴/魔法书 | 左右两页（5×8）+ 中缝 1 列 + 页内金色星点 + 整条书底/金色衬线 |
| 成就 Achievement | 奖杯 | 杯口/杯身/杯柄/杯座 + 两侧把手，中央镂空星形区域 |
| 设置 Settings | 齿轮 | 方形环（中间 6×6 透明孔）+ 4 正齿 + 4 角齿，全部整数矩形 |

> 齿轮单独用矩形构造（不是 16 行字符图），因为环 + 孔的像素图在 32px 下更容易读；其余三个用字符图。

## 3. 视觉规范

- 统一 16×16 网格、统一 2px 显示格；
- 剪影优先：远看能分出「卷轴 / 书 / 奖杯 / 齿轮」；
- 无细线（最细 1 格 = 2px）；
- 与界面既有米白/金色一致，不使用高饱和现代色；
- 历史页面的技能/道具图标仍用原有真实素材，不替换成功能图标。

# 素材需求（从玩法倒推）

> 本文件回答「**需要什么素材**」；「**已有什么**」看 `asset_inventory.md`；「**缺什么**」看 `asset_gap.md`。

## 1. 需求清单

| 类别 | 用途 | 规格要求 | 数量估算 | 状态 |
|---|---|---|---|---|
| 玩家角色 | 6 个角色，含待机 / 移动 / 受击 / 死亡 | 像素小人，统一画布与脚底基线 | 6 套 | 待盘点 |
| 敌人 | 怪潮主力（复用现有 70+ 素材优先） | 统一尺寸与朝向，可上白闪 | 70+ 复用 | 待盘点 |
| 精英 / Boss | 5~6 个 | 更大体量 + 更强演出 | 6 套 | 待盘点 |
| 技能表现 | 16 个基础技能 | 投射物 / 特效帧或程序化 | 16+ | 待盘点 |
| VFX | 命中 / 爆炸 / 升级 / 拾取 / 受击 | 帧动画或程序化，颜色可调 | 20+ | 待盘点 |
| UI 组件 | 面板 / 按钮 / 状态条 / 边框 | 九宫格可拉伸，竖屏友好 | 1 套 | 待盘点 |
| 图标 | 技能 / 行为模块 / 道具 / 属性 | 统一画布（建议 32x32 或 24x24） | 100+ | 待盘点 |
| 地图 | 节点图标 / 连线 / 地图背景 | 与战斗场景风格一致 | 1 套 | 待盘点 |
| 字体 | 中文像素字（简） | 小字号可读，含数字与标点 | 1~2 款 | 待盘点 |
| 音频 | 打击 / 升级 / 拾取 / UI / BGM | 可循环、可复用、体积可控 | 30+ | 待盘点 |

# 视觉风格规范

## 1. 风格定位 `[TBD]`

- 基调：**像素风**（硬性）。
- 世界观包装未定（`requirements.md` Q3）——世界观一旦确定，本文件必须同步
  「场景 / 敌人 / UI」三方面的视觉母题。

## 2. 可读性优先级（高于好看）

1. 玩家角色必须在怪潮中最显眼（描边 / 高饱和 / 特效轮廓）。
2. 敌方攻击预警必须与背景强对比。
3. 伤害数字、经验、拾取物在密集战斗中仍可辨。

## 3. 统一性检查清单

- [ ] 所有单位透视与光照方向一致
- [ ] 所有 UI 组件描边宽度一致
- [ ] 所有图标风格一致（同为像素描边或同为纯色块）
- [ ] 色板主色数量受控（Token 定稿时确定）

## 4. 禁止

- 直接复制现有商业产品的美术风格、角色设计或 UI 布局；
- 混用不同分辨率的像素素材而不做归一化；
- 用高清贴图冒充像素素材。

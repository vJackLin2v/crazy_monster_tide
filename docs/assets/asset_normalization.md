# 素材归一化规范（像素风）

## 1. 尺寸与缩放

- 战斗内单位按**整数倍**缩放；非整数倍会造成像素抖动与糊边。
- 同类素材（敌人 / 图标 / VFX）必须统一画布尺寸与脚底基线。
- 图标统一画布（建议 24x24 或 32x32，二选一后全局统一）。

## 2. 采样与过滤

- 纹理过滤 **Nearest**（默认值，不得逐图改成 Linear）。
- 缩放前先按像素网格对齐再渲染。

## 3. 颜色与风格

- 统一色板（待 `docs/ui/screen_specs.md` 的 Design Token 定稿后同步）。
- 不同来源素材必须做**调色统一**，否则会出现「拼图感」。
- 受击白闪用**运行时叠加**实现，不为每个单位单独做白闪贴图。

## 4. 透明与裁切

- 背景透明统一 PNG-32，边缘不得残留半透明杂边。
- 裁切紧贴像素边界（避免 1px 透明边导致对齐偏移）。

## 5. 命名与目录

```
assets/approved/<类别>/<name>_<尺寸>_<序号>.png
```

未过授权的素材放 `assets/source/`、`assets/internal/`，**不得**进 `approved/`。

# 素材授权与 Asset Gate

## 1. 铁律

> **素材不得因为「目录里有」就直接使用。**
> 任何素材进入正式生产路径（`assets/approved/`）前，必须完成本文件的登记。

## 2. Asset Gate 检查项

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 来源可追溯 | 有明确出处（URL / 作者 / 包名 / 生成方式） |
| 2 | 授权明确 | 许可类型写清楚（CC0 / CC-BY / 商用授权 / 自制 / AI 生成） |
| 3 | 允许商用 | 明确允许商业使用 |
| 4 | 允许修改 | 明确允许修改与再分发 |
| 5 | 署名要求 | 若需署名，写明署名位置与文案 |
| 6 | 与竞品无冲突 | 非某商业产品的私有素材 |
| 7 | 记录在案 | 已写入本文件表格 |

任一项不通过 → 素材状态 `blocked`，**不得**进入生产路径。

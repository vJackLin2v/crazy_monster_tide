## 1. 已确定规则 `[定]`

- 升级后从 **4 类**奖励中抽取：**技能 / 行为模块 / 道具 / 属性加成**。
- 每次**横向 3 选 1**（3 张选择卡）。
- 选到「行为模块」后进入**安装目标**步骤，只能选兼容槽位。
- 精英节点是高级道具 / 高级行为模块的**主要来源**。

## 3. 随机性要求 `[定]`

所有随机必须由**统一 RNG / Seed** 驱动，禁止在核心玩法里散布不可控随机；
测试必须能用固定 Seed 复现同一组奖励。

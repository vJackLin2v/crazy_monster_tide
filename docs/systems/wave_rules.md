## 1. 单局结构 `[定]`

```
第1波(18s) → 商店 → 第2波(18s) → 商店 → … → 第9波 → 商店
→ 第10波(BOSS，击杀即过关) → 商店 → … → 第20波(BOSS) → 收工结算 / 继续无尽
```

| 规则 | 值 |
|---|---|
| 一局总波数 | **20** |
| 每波时长 | `18 + floor((波数-1) / 3) × 3` 秒 → 第 1~3 波 18s，第 19~20 波 36s |
| BOSS 波 | **每 10 波**（10 / 20 / 30 …）；该波**无倒计时**，**击杀 BOSS 即过关** |
| 精英 | **每 3 波**一次（BOSS 波除外）；**第 12 波起一次出 2 只** |
| 通关条件 | 非 BOSS 波：**倒计时归零即过关**，场上残余怪清空并折算金币 |
| 失败条件 | 生命归零 → 结算 |
| 波间 | 每波结束进**商店**（不强制消费） |
| 打通 20 波后 | 可选 **收工结算** 或 **继续挑战（无尽）** |

## 2. 波次强度 `[定]`

| 项 | 值（实现） |
|---|---|
| 敌人血量 | **+24% / 波**（线性） |
| 敌人伤害 | **+12% / 波**（线性） |
| 刷怪间隔 | `max(0.18, 0.53 - 波数 × 0.022)` 秒 |
| 每批数量 | `min(5, 1 + floor(波数 / 3))` 只 |
| 生成位置 | 沿**可视矩形的外扩边框**向外 18~55 世界单位（**不写死半径**） |
| 敌人分波解锁 | 见 `cocos/assets/scripts/data/Enemies.ts` 的 `from` 字段 |
| BOSS 轮换 | 第 10 波恶魔领主 / 第 20 波地狱守望者 / 第 30 波起星光圣骑士 |

> **设计约束（硬）**：最快怪的速度必须**低于玩家移速**——"可躲"是硬条件，不是可调项。

**为什么是"沿矩形边框"而不是"按圆半径"**（踩过的坑 KI-009）：
按半对角线取圆，横向刷出的怪离画面边缘有 81 世界单位，50px/s 要走 1.6 秒才露面 →
用户反馈"怪都看不到"。沿矩形外扩则**任何方向都是"刚出画面"**，0.4~1 秒就走进来。

## 3. 商店 `[定]`

| 项 | 规则 |
|---|---|
| 货位 | **固定 4 个，竖向排列**（用户指令：做成土豆兄弟那样） |
| 商品 | 道具 / 行为模块 / 随机属性 / 治疗包 |
| 货币 | 金币（波次结算 + 击杀掉落） |
| 波次结算 | `12 + 波数 × 5 + 残余敌人掉落`，再乘 `(1 + 贪婪加成)` |
| 购买后 | **货位不消失，整行置灰并盖「已购买」**（用户指令：买完置灰） |
| 锁定 | 可锁定货位；**锁住的刷新不掉，且能留到下一波**（跨波携带） |
| 刷新 | 花金币刷新货架，价格递增：`2 + 已刷新次数` |
| 买到模块 | **直接进入「模块安装」界面**挑技能装上；也可点「先放背包」之后再说 |

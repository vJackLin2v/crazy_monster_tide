## 1. 单局结构 `[定]`

```
第 1 波(20s) → 商店 → 第 2 波(24s·中途出精英) → 商店 → 第 3 波(28s)
→ 商店 → 第 4 波(32s) → 商店 → 第 5 波(BOSS，击杀即通关) → 结算
```

| 规则 | 值 |
|---|---|
| 一局总波数 | 5 |
| 每波时长 | `20 + (波数-1) x 4` 秒（第 1 波 20s，第 4 波 32s） |
| 过关条件 | 非 BOSS 波：**倒计时归零即过关**（场上残余怪清空，不再攻击玩家） |
| 通关条件 | BOSS 波：**击杀 BOSS 即通关**（该波无倒计时） |
| 失败条件 | 生命归零 → 结算（失败） |
| 精英 | 第 2、3、4 波过半时各投放 1 只 |
| 波间 | 每波结束进入**商店**（不强制消费，可买可不买） |

## 2. 波次强度 `[定]`

- 敌人血量按波次线性提升（约 `+42% / 波`），伤害约 `+16% / 波`。
- 刷怪间隔随波次缩短，单批数量随波次增加。
- 敌人数量、强度的**具体数值属于实现细节**，可调，但**曲线方向不得反**（越后越强）。

## 3. 商店 `[定]`

| 项 | 规则 |
|---|---|
| 商品 | 道具 / 行为模块 / 治疗包 / 随机属性，共 4~6 件 |
| 货币 | 金币（波次结算 + 击杀掉落） |
| 波次结算 | `10 + 波数 x 6 + 残余敌人掉落` |
| 刷新 | 花费金币可刷新货架，每次递增（2 / 3 / 4 …） |
| 已购 | 商品买后消失，不补货 |

## 1. 定位 `[定]`

卖点明确要求 **「道具 / 属性 / 标签联动」**：三者必须能相互触发，而不是各自独立加成。

## 2. 已实现的联动：道具 → 技能标签 `[定]`

**机制**：道具给角色挂上"标签加成表"，技能结算时按**自己带的标签**去查表。

| 类型 | 字段 | 作用 | 例子 |
|---|---|---|---|
| 标签伤害加成 | `tagBonus[tag]` | 该标签技能**伤害** ×(1+b) | 余烬核心：`fire +0.25` |
| 标签冷却减免 | `tagCdr[tag]` | 该标签技能**冷却** ×(1-c) | 寒霜碎片：`ice +0.18` |
| 全标签加成 | `tagAll` | 所有标签技能伤害 ×(1+a) | 棱镜：`+0.08` |

技能带多个标签时**逐个相乘**（火 + 圣 的技能吃两份加成）。

## 3. 结算顺序 `[定]`（实现于 `game/SkillCalc.ts`）

```
技能本体基础值
  → 技能等级成长（冷却 ×0.94^(lv-1)，伤害 +22%/lv）
  → 行为模块（additive 加法 / tier 乘区 / unique 唯一）
  → 道具·标签冷却减免 tagCdr ×(1-c)        ← 联动在这里
  → 属性·攻速 haste（冷却 ÷ haste）
  → 道具·标签伤害加成 tagBonus / tagAll ×(1+b)  ← 联动在这里
  → 属性·攻击力 power
  → 模块·狙击 / 超载 的倍率
  → 最终伤害 → rollDamage（暴击判定）→ 单一入口 dealDamage
```

> **改这条链前先看 `SkillCalc.ts`**。伤害计算必须保持**单一入口**（`rules.md` §3）。

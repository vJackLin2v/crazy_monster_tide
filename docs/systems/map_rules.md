## 1. 已确定规则 `[定]`

- 地图为**树形路线**，玩家在每个节点处做选择。
- 不同节点承载**不同风险 / 收益**。
- 节点类型：**普通战斗 / 精英 / 商店 / 事件 / Boss**。
- **精英节点** = 高级道具与高级行为模块的主要来源。
- **Boss 节点** = 阶段性高潮。
- 首版 Boss 数量建议 5~6。

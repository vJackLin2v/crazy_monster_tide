## 2. 单局流程 `[定]`

1. **主界面** → 开始游戏 → **角色选择**（6 角色 × 正负天赋 × 初始技能）
2. 进第 1 波；战斗中玩家**只操作走位**（动态摇杆），**4 个技能全自动开火**
3. 击杀掉经验宝石 → 靠近**自动吸取**（拾取半径 85，靠近即吸，不必踩上去）
4. 升级 → **横向 3 选 1**：技能 / 行为模块 / 道具 / 属性加成（可跳过换 8 金币）
5. 选到**行为模块** → 进入**安装目标**步骤，装到兼容的技能槽位；也可「先放背包」
6. 暂停 → **Build 面板**：查看并重新分配技能、行为模块、道具、属性（4 页签）
7. 每波结束 → **波间商店**（4 个固定货位 + 锁定 + 刷新）
8. 第 10 / 20 波为 BOSS 波（击杀即过关）；其余波撑到倒计时归零即过关
9. 打通 20 波 → 选择「收工结算」或「继续挑战（无尽）」

## 3. 节奏目标 `[定]`（2026-10-17 补实测值）

| 项 | 目标 / 实测 | 说明 |
|---|---|---|
| 单局时长 | **约 8 分 51 秒**（纯战斗） + 商店时间 | 20 波各 `18+⌊(n-1)/3⌋×3` 秒，合计 531 秒 |
| 单波时长 | 18 → 36 秒 | 第 1~3 波 18s，第 19~20 波 36s |
| 升级曲线 | `所需经验 = 5 + 等级 × 3.2` | 越到后面升级越慢 |
| 难度爬升 | **波数驱动**：敌人血量 +24%/波、伤害 +12%/波 | 见 `wave_rules.md` §2 |
| 刷怪密度 | 第 1 波约 2 只/秒，在屏 4~5 只 | 按"刷怪率略高于玩家 DPS"标定，早期缓、随技能数加速 |
| 死亡条件 | 生命归零 → 结算 | 无复活 |
| 结算口径 | 存活时间 / 击杀 / 等级 / 推进到第几波 / 金币 / seed + **本局 Build 回顾** | 见 UI 规格 v1.1 §2.9 |

> **为什么第 1 波不能太猛**：玩家开局只有 1 个技能，DPS ≈ 0.8 只/秒。
> 实测 2.6 只/秒时玩家**第 1 波就死**；1.4 只/秒则屏幕太空（在屏仅 2.6 只）。
> 最终取 2.0 只/秒 —— 这条曲线是**三轮实测标定**出来的，不是拍脑袋。

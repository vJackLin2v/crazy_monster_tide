## 1. 三层层级

```
局外（元）      →  一局（Run）        →  一场战斗（Wave）
选角色 / 解锁       树形地图逐节点推进      怪潮来袭 → 自动清怪 → 升级 3 选 1
```

## 2. 单局流程 `[定]`

1. 选择角色（固定被动 = 正向 Buff + 负向 Buff）。
2. 进入树形地图，逐节点推进：普通战斗 / 精英 / 商店 / 事件 / Boss。
3. 战斗中：玩家只操作走位（动态摇杆），技能自动开火。
4. 获得经验 → 升级 → 从 4 类奖励中横向 3 选 1：技能 / 行为模块 / 道具 / 属性加成。
5. 行为模块选择后进入「安装目标」步骤，装到兼容的技能槽位。
6. 暂停 → Build 面板：查看并重新分配技能、行为模块、道具、属性。
7. Boss 节点作为阶段性高潮；局终结算。

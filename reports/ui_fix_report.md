## 4. 未完成 / 风险

1. **滚动惯性**未实现：当前是 1:1 跟手 + 边界停止，松手即停（任务书要求"惯性滚动"）。需要补速度采样 + 衰减动画，属 P2；
2. **真机验证未做**：本机没有微信开发者工具/手机，所有 UI 结论来自浏览器构建（同分辨率、同代码）；
3. 结算页「本局技能」在技能 <4 时只显示已拥有的，空位不占格子（符合"不塞满"原则）；
4. 热区审计只覆盖有命名的 `*Hit` 节点，极个别以 panel 直接做热区的控件未纳入（如锁定按钮），但已在阶段 0 人工核对过尺寸。

### 🔴 门禁最重要的发现

**需求书 §7 的「已有约 70+ 怪物素材」是错的 —— 那批素材不能用。**

| 事实 | 说明 |
|---|---|
| 95 怪物动画表 / 113 玩家单位表 / Boss 立绘 / 音效 | 全部是 **`Slotbound`（商业游戏）解包素材** |
| 母本自身审计 | `internal-use-only`（禁商用 / 禁再分发 / 禁进仓库） |
| 母本为什么能用 | 它定性为「学习/内部演示，**不发布**」 |
| 我们的处境 | 目标是**上架微信小游戏** → **一个都不能用** |

> 若不盘这一遍，我们会在 Cocos 里用解包素材做完整个游戏，然后在上架前发现全部要换。

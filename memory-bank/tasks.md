## M9 交付物

用户指令：「先调观感 —— 单位 1x 放大到更'有大作感'，同时调整镜头与怪潮密度」。

### 先算后做（不拍脑袋）

```
屏幕 360x640 ｜ 单位原生 32px
 1x → 32px 占屏高 5.0%   横向排 11 个   ← 没有主角感
 2x → 64px 占屏高 10.0%  横向排 5.6 个  ← 落在 Brotato 一类的主角比例区间（8~13%）
 3x → 96px 占屏高 15.0%  横向排 3.8 个  ← 偏大，怪潮放不下
→ ZOOM = 2（必须整数倍，否则像素糊）
```

### 三处联动（单独放大 = 挤爆屏幕，必须一起改）

| 项 | 旧 | 新 |
|---|---|---|
| 渲染缩放 | 1x | **2x** |
| 可视世界 | 360x640 | **180x320** |
| 竞技场 | 540x820 | **620x940**（风筝空间更足） |
| 每批刷怪 | `min(5, 1+⌊w/4⌋)` | **`min(3, 1+⌊w/6⌋)`** |
| 刷怪间隔 | `max(0.30, 0.95-w*0.04)` | **`max(0.40, 1.15-w*0.045)`** |
| 生成半径 | 235~280 | **195~235**（可视半对角线 184，刚好屏外） |
| 第 20 波总刷怪 | 600 | **270** |
| 玩家/敌人碰撞半径 | 9 / 8~13 | **12 / 10~14**（同步放大，避免"撞上没伤害"） |

### 顺带修的一个体验问题

**伤害数字原本画在世界空间** → 被 2x 放大后变成糊字。
改为 `CX.restore()` 之后用**屏幕坐标**绘制，字号恒定、边缘清晰。

## 2. 与引擎无关的硬约束 `[定]`

- 逻辑分辨率 **360 x 640**，竖屏，fitWidth。
- 纹理过滤 **Nearest**。
- 战斗对象数量可能上百：需要**对象池**，避免每帧创建 / 销毁。
- 随机统一走 RNG / Seed（见 `docs/testing/seed_and_harness.md`）。
- 伤害计算必须**单一入口**（便于钩子、日志、复现）。

## 3. 模块边界（建议）

```
core/        RNG、事件总线、对象池、时间
data/        技能 / 模块 / 道具 / 角色 / 地图的配置表（数据驱动）
systems/     技能、行为模块、属性、标签联动、奖励、地图、战斗
ui/          HUD、升级 3 选 1、Build 面板、地图、结算
platform/    微信 / 抖音适配、安全区、触摸
assets/      过 Gate 的正式素材
tests/       单元 / 集成 / 场景 / 视觉
```

## 4. 数据驱动原则 `[定]`

技能、行为模块、道具、属性、地图节点、角色天赋**全部配置化**，
代码只负责解释规则；内容扩充不得改代码。
